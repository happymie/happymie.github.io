GRU

GRU 用 reset/update 两门和单一隐藏状态完成记忆更新，结构比 LSTM 更简洁。Simplifies gated recurrence by merging cell and hidden states into a single vector h_t interpolated via an update gate z_t and a reset gate r_t. E0

01 / 上一代瓶颈Prior limitation

vanilla RNN 梯度不稳，LSTM 门控和状态较复杂LSTM required three separate gates and dual state vectors, increasing parameter count and overfitting risk on small clinical cohorts.

02 / 核心想法Core idea

以 update/reset gates 控制隐藏状态保留与重置，简化门控循环结构Eliminate the separate cell state and control memory retention versus new candidate overwriting with a single complementary update gate z_t.

03 / 医学适配Medical adaptation

常用于 ECG、EEG、生命体征和纵向临床序列的小数据基线Widely used in compact wearable biosignal monitors, GRU-D missing-value clinical EHR time series, and edge medical devices.
