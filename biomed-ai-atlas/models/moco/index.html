MoCo

由 EMA key encoder 维护一致编码、由 FIFO queue 提供大规模跨 batch 负样本的对比字典。Decouples contrastive negative dictionary size from mini-batch size using a FIFO queue of encoded keys updated via a momentum (EMA) encoder. E0
