EVLF-FM

将通用视觉、疾病级全局特征与像素级空间特征一起接入语言模型。先以医学指令监督微调，再通过组相对策略优化学习诊断与定位，并对齐解释中的临床发现。A language model combines general visual tokens, global disease features and spatial pixel features. Medical instruction tuning precedes group-relative policy optimization for diagnosis, grounding and clinically aligned explanations. E1

结构总览ARCHITECTURE OVERVIEW

EVLF-FM，从结构到机制。EVLF-FM: structure to mechanism.

输入INPUT

医学二维图像与文字问题或指令。作者实现基于 InternVL3-8B，并为疾病编码器与像素编码器分别准备图像张量；体数据实验使用所选切片。A medical 2D image and a textual question or instruction. The InternVL3-8B implementation prepares separate image tensors for disease and pixel encoders; volumetric-study examples use selected slices.

→
输出OUTPUT

自回归生成诊断、图像问答及解释文本；视觉定位任务输出边界框坐标。像素编码器提供空间特征，最终定位输出形式由任务指令与标注规定。Autoregressive diagnostic answers, visual-question answers and explanations; grounding tasks produce bounding-box coordinates. The pixel encoder supplies spatial features, while instructions and annotations define the output format.

关键设计DESIGN DECISION

先做医学指令监督微调，再以任务奖励和临床解释对齐奖励优化同一生成策略。Follow medical instruction tuning with task rewards and clinical reasoning alignment.

  1. 01

    准备图像与问题Prepare image and question

    同一医学图像按各编码器要求分别预处理，文字指令规定诊断、问答或定位任务。二维切片与完整体积的输入范围分别理解。Preprocess the same image for each encoder. The instruction selects diagnosis, VQA or grounding; a 2D slice has a different scope from a full volume. E1

  2. 02

    保留通用视觉标记Retain general visual tokens

    InternVL3 的视觉路径提取图像标记，经视觉连接器映射到语言嵌入空间，保留通用图文模型的视觉上下文。InternVL3 extracts visual tokens and projects them into the language embedding space, retaining the general VLM context. E1

  3. 03

    编码全局疾病线索Encode global disease cues

    MedImageInsight 的 DaViT-Huge 路径提取全局疾病表征。独立连接器将该表征转为一个疾病提示标记。The MedImageInsight DaViT-Huge path extracts a global disease representation. A dedicated connector produces a disease-prompt token. E1

  4. 04

    保留密集空间网格Preserve a dense spatial grid

    MedSAM 图像编码器产生空间特征，展平后逐位置投影。作者主配置保留 256 个空间标记，为局部病灶与解剖定位提供细节。MedSAM supplies spatial features that are flattened and projected position by position. The main configuration retains 256 spatial tokens for local anatomy and findings. E1

  5. 05

    在标记序列中融合Fuse in the token sequence

    将通用图像标记、一个疾病标记和空间标记拼接，填入语言模型的图像上下文位置，与文字一起处理。主训练脚本关闭可选的第二疾病编码器。Concatenate general visual, disease and spatial tokens at the LLM image-context positions alongside text. The main script disables the optional second disease encoder. E1

  6. 06

    以医学指令监督微调Tune on medical instructions

    第一阶段以参考回答的负对数似然学习任务。基础参数冻结，以 LoRA 与连接器适配医学内容；训练脚本显式配置语言与辅助视觉编码器的适配器。Stage one learns reference responses with negative log-likelihood. Frozen base weights are adapted through LoRA and connectors, with explicit language and auxiliary-encoder settings. E1

  7. 07

    为同一问题采样一组回答Sample a group of responses

    将合并后的监督微调模型作为策略初始化。对同一图像与问题生成多个候选，组内奖励差异决定相对优势。Initialize the policy from merged SFT adapters. Generate several responses to the same input; reward differences within that group define relative advantages. E1

  8. 08

    组合任务与解释奖励Combine task and reasoning rewards

    论文用诊断正确性和定位交并比描述任务奖励；归档代码细分为标签集合重合与边界框交并比。解释奖励匹配临床发现，并考虑遗漏、无依据陈述与矛盾。The paper describes diagnostic correctness and grounding IoU; archived code uses label-set overlap and box IoU. Reasoning alignment considers clinical matches, omissions, unsupported statements and contradictions. E1

  9. 09

    按组相对优势更新Update with group-relative advantages

    奖励在组内标准化，裁剪策略比率控制更新，KL 项约束与冻结参考策略的偏移。第二阶段冻结视觉路径和连接器，仅更新语言 LoRA。Normalize rewards within the group, clip policy ratios and regularize against a frozen reference with KL. Stage two freezes vision and connectors and updates language LoRA. E1

  10. 10

    联合阅读回答与定位Read answer, explanation and location

    分别核对诊断标签、边界框与解释中的影像发现。解释属于事后生成的文本；论文通过人工评价与忠实度分析检验它与证据的关系。Check diagnostic labels, boxes and described findings separately. Explanations are post hoc text; the paper examines their evidence alignment through human evaluation and faithfulness analyses. E1

01 / 上一代瓶颈Prior limitation

通用视觉语言模型的高层语义未必保留医学诊断线索与局部病灶细节。General VLM semantics can miss disease-specific cues and local findings.

02 / 核心想法Core idea

让通用视觉、全局疾病与局部空间特征共同进入语言模型的上下文。Combine general vision, global disease and local spatial features in the LLM context.

03 / 医学适配Medical adaptation

统一诊断、图像问答与边界框定位，同时分别评估回答正确性与解释质量。Support diagnosis, VQA and box grounding while evaluating answer quality and explanations separately.

原理与医学适配Principles and medical adaptation

设计原理Design principles

  • 三条视觉路径各有职责：通用图像标记提供上下文，疾病提示概括全局，密集空间标记保留局部线索。General visual tokens provide context, a disease prompt summarizes global cues, and dense spatial tokens preserve local information. E1
  • 连接器把不同编码器的特征映射到同一语言嵌入宽度，再拼接为视觉上下文。Dedicated connectors map encoder features into the LLM width before visual-context concatenation. E1
  • 主配置 use_tsm2=False，仅保留 MedImageInsight 与 MedSAM 两个医学辅助编码器；代码的可选分支不等于主模型。The main use_tsm2=False configuration retains MedImageInsight and MedSAM; optional code branches are separate variants. E1
  • 监督微调学习参考回答；组相对策略优化比较同一问题的一组采样回答，两阶段的目标与参数更新范围不同。SFT learns reference responses; GRPO compares grouped sampled responses, with different objectives and trainable parameters. E1
  • 组内奖励标准化提供相对优势，无须另训练价值网络；策略裁剪与 KL 项控制更新幅度。Within-group reward normalization supplies advantages without a learned critic; clipping and KL control policy updates. E1
  • 解释对齐按句匹配临床内容，以覆盖度与忠实度的调和平均兼顾遗漏与冗余。作者归档还加入同数据集对照参考，减少通用模板获得的奖励。Sentence-level alignment balances completeness and faithfulness with a harmonic mean. The archive adds same-dataset distractor references to reduce generic-template rewards. E1
  • 论文的诊断正确性描述与代码的标签集合 F1 实现分别记录；定位训练的连续交并比与阈值化评估指标分别阅读。Record the paper’s diagnostic correctness description separately from code’s label-set F1; distinguish continuous training IoU from thresholded evaluation. E1
  • 归档主训练配置的强化学习数据为分类与定位；问答评估不等于对所有开放式回答直接施加强化学习奖励。The archived main RL configuration lists classification and grounding data; VQA evaluation does not imply RL on all open-ended answers. E1
  • 首次预印本与期刊版的数据构成和结果有所变化。本页采用期刊版机制与原图，不混用两个版本的数值。The preprint and journal versions differ in data composition and results. This page uses the journal mechanism and original without mixing numerical results. E1

医学边界Medical scope

  • 图像输入：检查模态、所选切片、缩放与各编码器的归一化方式，再解释输出覆盖的空间范围。Input: verify modality, selected slice, resizing and encoder normalization before interpreting spatial coverage. E1
  • 诊断任务：核对疾病类别与标签集合，区分单标签正确率、多标签重合与校准。Diagnosis: check class definitions and label sets, distinguishing single-label accuracy, multi-label overlap and calibration. E1
  • 视觉定位：对照原图检查边界框坐标、图像缩放与标注定义；连续交并比和阈值命中率各有意义。Grounding: inspect box coordinates, resizing and annotation conventions alongside continuous IoU and thresholded hits. E1
  • 解释阅读：把文本中的临床发现逐项对应影像或参考描述，并检查否定、遗漏与新增陈述。Explanations: map clinical statements to image findings or reference text and check negation, omissions and added claims. E1
  • 迁移评估：分别记录内部数据、外部队列、零样本和少样本协议，以及机构与设备差异。Transfer: separate internal and external cohorts, zero-shot and few-shot protocols, institutions and devices. E1
