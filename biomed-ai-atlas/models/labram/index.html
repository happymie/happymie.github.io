01 / 上一代瓶颈Prior limitation

电极数、记录长度和任务差异使一任务一模型难迁移EEG datasets vary wildly in electrode montage (16 to 128 channels), sampling rates, and low SNR, preventing cross-dataset pretraining.

02 / 核心想法Core idea

以 channel patches、VQ neural tokenizer 和 masked code prediction 统一异质 EEGSegment each EEG channel into fixed-duration temporal patches, learn a discrete neural codebook predicting frequency amplitude/phase, and pretrain a Transformer with spatial+temporal embeddings via masked code prediction.

03 / 医学适配Medical adaptation

支持 EEG 分类、检测和 BCI 的迁移与少样本学习Canonical foundation model for cross-montage EEG abnormality classification, event detection, and brain–computer interfaces.

原理与医学适配Principles and medical adaptation

设计原理Design principles

  • 把异质 EEG 统一为 channel-time patches，并显式编码电极身份与时间位置。Core Hypothesis: Segment each EEG channel into fixed-duration temporal patches, learn a discrete neural codebook predicting frequency amplitude/phase, and pretrain a Transformer with spatial+temporal embeddings via masked code prediction. E0
  • VQ neural tokenizer 将连续信号变为离散语义目标，使 masked modeling 不必逐样本回归原始振幅。Architectural Delta: Spectrum-guided discrete neural tokenizer + factorized electrode-spatial and temporal embeddings unifying ~2,500 hours across 20 heterogeneous EEG cohorts. E0
  • 大规模 Transformer 在跨时间和跨通道维度共享参数，迁移能力依赖 montage 与预处理对齐。Mathematical Formalism: Fourier-Spectrum Guided Neural Vector Quantization + Symmetric Masked EEG Code Prediction. E0

医学边界Medical scope

  • 可迁移到 EEG 分类、事件检测和 BCI 的少标签任务，是领域预训练的重要代表。Clinical Translation: Canonical foundation model for cross-montage EEG abnormality classification, event detection, and brain–computer interfaces. E0
  • 跨设备、跨人群、缺失电极和独立临床队列证据仍有限；离散 tokenizer 也可能忽略低幅但关键事件。Evidence & Safety Boundary: Significant methodological leap for heterogeneous neurophysiology; clinical cross-hospital sensitivity and false-alarm calibration require ongoing validation. E0
