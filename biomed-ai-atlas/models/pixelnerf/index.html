pixelNeRF

pixelNeRF 将每个 3D 点与其投影像素的 CNN 特征绑定，使 NeRF 从单场景优化器变为跨场景条件模型。Conditions a coordinate NeRF MLP on pixel-aligned 2D CNN feature vectors projected from 1 or a few input views, turning NeRF from a per-scene optimizer into a feed-forward cross-scene prior. E0

01 / 上一代瓶颈Prior limitation

原始 NeRF 每个场景都需多视图和长时间优化Original NeRF had no cross-scene prior and collapsed completely when given only 1–3 input views.

02 / 核心想法Core idea

从输入图像提取像素对齐特征并条件化 NeRF，使其跨场景推断新对象Extract a spatial CNN feature pyramid from each input view, project any 3D query point x onto the 2D image planes via camera intrinsics/extrinsics, and feed the bilinearly sampled features into the NeRF MLP.

设计原理Design principles

  • 3D query 点先投影回参考图，读取与该点对齐的局部图像特征。Core Hypothesis: Extract a spatial CNN feature pyramid from each input view, project any 3D query point x onto the 2D image planes via camera intrinsics/extrinsics, and feed the bilinearly sampled features into the NeRF MLP. E0
  • NeRF MLP 不再只记忆单场景参数，而被 CNN 特征条件化以学习跨场景先验。Architectural Delta: Preserves explicit projective geometry via pixel-aligned local features rather than compressing the input into a single global latent vector. E0
  • 一张或少量参考图经前馈编码后即可对新对象推断和渲染。Mathematical Formalism: Pixel-Aligned View-Space CNN Feature Conditioning of Continuous Radiance Fields. E0

医学边界Medical scope

  • 启发 sparse-view X-ray、内镜和患者特异解剖场中的图像条件神经场。Clinical Translation: Directly inspires sparse-view dual/single X-ray to 3D CT neural field priors (e.g., PerX2CT, DIF-Net). E0
  • 少视图未观测区域仍由训练先验补全；医学应用必须区分可见证据与先验生成部分。Evidence & Safety Boundary: Foundational few-view conditional neural field; projective feature occlusion must be adapted for transmission X-ray imaging. E0
