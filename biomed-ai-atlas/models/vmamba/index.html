01 / 上一代瓶颈Prior limitation

将图像按单条 1D 序列展平会破坏二维拓扑Flattening a 2D image into a single 1D causal raster scan destroys 2D spatial proximity along non-scan directions.

02 / 核心想法Core idea

以四方向 2D selective scan 和层级 VSS block 建模视觉结构Traverse 2D feature grids simultaneously along four complementary corner-to-corner paths before summing the selective scan outputs.

03 / 医学适配Medical adaptation

作为医学 2D SSM 的视觉初始化和对照；原生 3D 仍需改造扫描与层级结构Serves as the primary 2D vision SSM backbone and initialization for medical 2D segmentation and classification.

原理与医学适配Principles and medical adaptation

设计原理Design principles

  • 四向 cross-scan 缓解单条 raster 序列对二维邻接关系的破坏。Core Hypothesis: Traverse 2D feature grids simultaneously along four complementary corner-to-corner paths before summing the selective scan outputs. E0
  • selective SSM 提供长程传播，patch merging 提供视觉多尺度。Architectural Delta: SS2D four-way cross-scan module embedded within a hierarchical Visual State-Space (VSS) backbone. E0
  • 扫描顺序本身成为新的归纳偏置，线性阶仍乘以方向数。Mathematical Formalism: VMamba Four-Way 2D Cross-Scan & Merge (SS2D). E0

医学边界Medical scope

  • 可作为医学 2D SSM backbone 或后续 3D 扩展的机制参考。Clinical Translation: Serves as the primary 2D vision SSM backbone and initialization for medical 2D segmentation and classification. E0
  • 迁移到体数据需要新增轴向/多方向扫描，不能把 2D 权重直接等同原生 3D 表示。Evidence & Safety Boundary: Important visual SSM baseline; native 3D volumetric extension requires tri-axial or multi-directional scan adaptations. E0
