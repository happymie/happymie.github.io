MedGemma

以医学图文训练的 MedSigLIP 编码图像，将视觉表示与文本一起送入 Gemma 3，逐词生成医学回答。模型集合包括 4B 与 27B 多模态模型及 27B 纯文本模型。A medically trained MedSigLIP encoder supplies visual representations to Gemma 3 alongside text for autoregressive medical answers. The collection contains 4B and 27B multimodal variants and a 27B text-only variant. E1

结构总览ARCHITECTURE OVERVIEW

MedGemma，从结构到机制。MedGemma: structure to mechanism.

输入INPUT

多模态变体接收医学图像与文本，可交错组织在对话中；27B Text 仅接收文本。期刊的视觉输入为 896×896，像素归一化至 (−1,1)。本页采用原始二维发布，1.5 的体数据流程属于后续版本。Multimodal variants take medical images and text interleaved in a conversation; 27B Text takes text only. The journal vision input is 896×896 with pixels normalized to (−1,1). This page covers the original 2D release; 1.5 volumetric workflows belong to a later version.

→
输出OUTPUT

多模态与纯文本 MedGemma 均输出生成文本，例如图像问答、报告草稿和医学摘要。独立 MedSigLIP 输出用于分类与检索的表示，不直接生成回答，也不等于 MedGemma 的语言解码器。Both multimodal and text-only MedGemma produce generated text, including visual answers, draft reports and medical summaries. Standalone MedSigLIP supplies representations for classification and retrieval rather than generating answers.

关键设计DESIGN DECISION

把医学视觉编码器、交错图文预训练与任务后训练分开描述，提供多模态 4B/27B 与纯文本 27B 的互补选择。Separate medical vision enhancement, interleaved multimodal pretraining and task post-training; offer complementary 4B/27B multimodal and 27B text-only variants.

  2. 02

    组织图像与问题Compose images and a question

    把图像和文字放进具有角色的消息结构，保留图像与问题之间的对应关系。作者示例用聊天模板构造模型输入，并在最后加入生成提示。Place images and text in role-structured messages while preserving their correspondence. The author example uses a chat template and adds a generation prompt. E1

  3. 03

    图像预处理Image preprocessing

    期刊的多模态编码器使用 896×896 图像和 (−1,1) 像素归一化。处理器管理模型需要的图像张量、文字标记和掩码；输入文件的原始尺寸不等于编码器尺寸。Journal multimodal encoding uses 896×896 images normalized to (−1,1). The processor builds required image tensors, text tokens and masks; a file’s original size is not the encoder size. E1

  4. 04

    MedSigLIP 医学视觉编码MedSigLIP medical vision encoding

    400M 规模的 SigLIP 视觉编码器经过医学图文增强，提取影像表示。训练同时保留通用领域数据，使专科适配与原有视觉能力在同一编码器中协调。A 400M SigLIP vision encoder is enhanced with medical image–text data to extract image representations. General-domain replay balances medical adaptation with existing visual capability. E1

  5. 05

    对接视觉与语言Connect visual and language representations

    视觉编码结果沿 Gemma 3 的多模态接口送入语言模型，与文本条件共同形成回答上下文。该节点标明视觉表示与文字条件的衔接位置。Visual encoding enters the Gemma 3 multimodal interface and forms the answer context alongside text. This node locates the connection between visual representations and text conditions. E1

  6. 06

    Gemma 3 语言建模Gemma 3 language modeling

    模型基于已经训练的 Gemma 3。多模态路线在视觉增强后继续进行包含交错图文的预训练，使解码器适应医学视觉表示；纯文本 27B 路线单独处理。The model starts from pretrained Gemma 3. After vision enhancement, multimodal pretraining with interleaved images and text adapts the decoder to medical visual representations. The text-only 27B route is separate. E1

  7. 07

    逐标记生成Generate tokens autoregressively

    作者示例执行 model.generate，限制新生成标记数，并支持确定性解码。输出依赖所给图像、问题和上下文；生成长度与输入长度应分别管理。The author example calls model.generate with a limit on new tokens and deterministic decoding. Outputs depend on images, question and context; input and generated lengths are managed separately. E1

  8. 08

    提取回答标记Extract answer tokens

    固定示例先记录输入 token 长度，再从生成序列中去掉输入前缀，以处理器或分词器解码新增部分，避免把问题本身重复当成模型回答。The pinned example records input-token length, removes that prefix from the generated sequence and decodes only the newly generated tokens, avoiding repetition of the prompt as an answer. E1

  9. 09

    关联影像证据阅读Read with the image evidence

    问答、报告生成与医学摘要是不同输出任务。阅读回答时检查影像所见、问题要求和遗漏信息；对于分类或检索，可选独立 MedSigLIP 表征与相应评估协议。Visual answering, report generation and summarization are distinct tasks. Read answers against image findings, the question and omissions. Classification or retrieval can instead use standalone MedSigLIP with a suitable evaluation protocol. E1

  10. 10

    按任务验证结果Validate by task

    论文区分图像问答、胸片分类、报告评估和医学文本任务。复现时固定数据划分、提示词、模型标识与解码方式，不把不同任务的分数当作同一种准确率。The paper separates visual QA, chest-image classification, report evaluation and medical text tasks. Reproduction fixes splits, prompts, model identifiers and decoding rather than treating all scores as one accuracy. E1

01 / 上一代瓶颈Prior limitation

通用视觉语言模型能理解多种输入，但医学中的细粒度所见、专科术语和任务协议仍需要专门适配。General vision-language models handle diverse inputs, while fine medical findings, terminology and task protocols require domain adaptation.

02 / 核心想法Core idea

沿用 Gemma 3 多模态骨架，先增强医学视觉表示，再让语言模型适应新的图像表示与医学任务。Retain Gemma 3’s multimodal backbone, enhance medical visual representations, then adapt language modeling to the new representations and tasks.

03 / 医学适配Medical adaptation

医学图文覆盖放射影像、病理、眼底与皮肤图像，文本任务包括问答和摘要。独立 MedSigLIP 服务于表征型任务。Medical image–text data span radiology, pathology, ophthalmology and dermatology. Text tasks include answering and summarization; standalone MedSigLIP supports representation tasks.

原理与医学适配Principles and medical adaptation

设计原理Design principles

  • 图像编码与语言生成承担不同功能。MedSigLIP 把影像映射为可用表示，Gemma 3 根据图像表示和文字上下文生成新标记；不能把相似度检索接口等同于问答接口。Image encoding and language generation have different roles. MedSigLIP maps images to representations; Gemma 3 generates tokens conditioned on visual representations and text. Similarity retrieval is a different interface from question answering. E1
  • 期刊多模态视觉输入为 896×896。独立发布的 MedSigLIP 使用 448×448，分享视觉权重并适配位置编码，以降低独立表征实验的计算成本；两个分辨率对应不同使用路径。Journal multimodal vision input is 896×896. Standalone MedSigLIP uses 448×448, sharing vision weights with adapted positional embeddings to reduce representation-experiment cost. These resolutions belong to different usage paths. E1
  • 视觉增强阶段保留通用训练数据，并在混合中加入医学图文。随后多模态预训练重新适配视觉表示与语言模型；训练混合比例属于阶段与实验设定，不能当作推理参数。Vision enhancement retains general training data and mixes in medical image–text data. Multimodal pretraining subsequently adapts the vision-language connection. Training mixture ratios belong to specific stages and experiments, not inference parameters. E1
  • 期刊明确多模态变体采用视觉增强、多模态预训练和后训练阶段；27B Text 采用后训练路线。相同的参数规模不意味着相同输入模态或训练过程。Journal multimodal variants undergo vision enhancement, multimodal pretraining and post-training; 27B Text uses the post-training route. Equal parameter scale does not establish equal input modalities or training paths. E1
  • 固定作者示例将 27b-text-it 分流到 text-generation，其余多模态变体进入 image-text-to-text。模型标识决定所支持的输入路径。The pinned author example sends 27b-text-it to text-generation and multimodal variants to image-text-to-text. Model identifiers determine the supported input path. E1
  • 输入 token 与新增 token 的边界决定展示什么内容。先保存 input_ids 的长度，再截取生成序列的新部分，可以避免把输入问题误记为模型输出。The boundary between input and new tokens determines what is displayed. Recording input_ids length and slicing it from generated sequences avoids treating the question as model output. E1
  • 量化和设备映射属于部署策略。作者示例支持可选 4-bit 加载与 bfloat16；这不改变原论文的模型身份，也不能据此推断任意设备上的速度或精度。Quantization and device mapping are deployment choices. The author example supports optional 4-bit loading and bfloat16; these do not change model identity or establish speed and accuracy on arbitrary devices. E1
  • 本文公式说明给定图像与文本条件后的自回归分解。完整训练还包含视觉增强、多模态预训练与后训练各阶段的监督和数据组成。The formula explains autoregressive factorization conditioned on images and text. Complete training also includes the supervision and data mixtures of vision enhancement, multimodal pretraining and post-training. E1
  • 技术报告首次公开于 2025-07-07，期刊发表于 2026-10-06。版本日期、模型发现日期、本站预览日期与正式发布日期分别记录，不把期刊日期当作首次公开时间。The technical report first appeared on 2025-07-07; the journal article appeared on 2026-10-06. Release, discovery, preview and formal publication dates are recorded separately. E1

医学边界Medical scope

  • 胸部影像问答：同时给出图像与明确问题，区分可见征象、位置描述和问题中额外提供的信息。Chest-image QA: supply an image and explicit question; distinguish visible findings, localization and additional facts supplied in the question. E1
  • 报告生成：以参考报告和影像所见共同评估，关注遗漏、额外发现和措辞，而非只比较文本是否流畅。Report generation: evaluate against both reference reports and image findings, checking omissions, extra findings and phrasing rather than fluency alone. E1
  • 数字病理：本页原始版本以二维图像或图块进行理解；全切片的采样、聚合与新版流程需另行固定。Digital pathology: the original release interprets 2D images or patches; whole-slide sampling, aggregation and newer workflows require separate versioning. E1
  • 眼底与皮肤图像：按任务标签、疾病谱、设备与人群设计验证；不同图像来源会改变输入分布。Retinal and skin images: validate against task labels, disease spectrum, devices and populations; image provenance affects the input distribution. E1
  • 医学文本：27B Text 可用于文本问答、摘要与合成 EHR 任务，图像条件需要选择多模态模型。Medical text: 27B Text supports text QA, summarization and synthetic-EHR tasks; image conditioning requires a multimodal variant. E1
  • 表征任务：独立 MedSigLIP 可用于图像检索和分类实验，评价检索排序与分类阈值时采用各自协议。Representation tasks: standalone MedSigLIP supports retrieval and classification experiments, each with its own ranking or threshold protocol. E1
