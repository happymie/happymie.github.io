01 / 上一代瓶颈Prior limitation

稀疏 CBCT 重建缺细节，监督网络需大量成对训练数据Applying RGB NeRF directly to X-ray projections violated transmission physics, while Fourier MLP encodings took hours to optimize per patient.

02 / 核心想法Core idea

用坐标网络表示 X-ray attenuation，并最小化输入投影的重投影误差Model a view-independent scalar attenuation field μ(x) using multi-resolution hash grid encoding (Instant-NGP) supervised purely by line-integral projection residuals.

03 / 医学适配Medical adaptation

适用于 phantom/人体 sparse-view CBCT 的自监督 per-case reconstruction；需区分模拟投影与真实 acquisitionFast, self-supervised per-patient sparse-view CBCT reconstruction requiring zero external training datasets.

原理与医学适配Principles and medical adaptation

设计原理Design principles

  • 把 NeRF 的 radiance field 改写为非负 attenuation field，使渲染符合 X-ray 射线积分。Core Hypothesis: Model a view-independent scalar attenuation field μ(x) using multi-resolution hash grid encoding (Instant-NGP) supervised purely by line-integral projection residuals. E0
  • 只用输入投影重投影误差做 per-case self-supervision，不需要成对 ground-truth CT。Architectural Delta: Physically faithful Beer–Lambert line integral + multi-resolution learnable hash table reducing self-supervised 3D CBCT reconstruction to minutes. E0
  • 多分辨率 hash encoding 提升坐标场的训练速度和细节表达，但不能补足未观测的零空间。Mathematical Formalism: Beer–Lambert Logarithmic Line-Integral Reprojection Consistency Over Multi-Resolution Hash Grids. E0

医学边界Medical scope

  • 适合 sparse-view CBCT 的病例级自监督重建，可在连续坐标中任意分辨率查询。Clinical Translation: Fast, self-supervised per-patient sparse-view CBCT reconstruction requiring zero external training datasets. E0
  • 真实散射、束硬化、金属和校准误差若未纳入 renderer，会被场错误吸收为解剖；模拟与真实证据应分开报告。Evidence & Safety Boundary: Correct physics adaptation of NeRF to tomography; without an external population prior, extreme view sparsity still exhibits null-space streaks. E0
