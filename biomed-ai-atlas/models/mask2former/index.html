01 / 上一代瓶颈Prior limitation

语义、实例和全景分割依赖各自专用结构，全图 cross-attention 昂贵Semantic, instance, and panoptic segmentation relied on fragmented task heads, while global cross-attention converged slowly.

02 / 核心想法Core idea

把分割统一为一组 mask queries 的分类与掩膜预测Formulate all segmentation tasks as mask-classification set prediction using learnable object queries and masked cross-attention.

原理与医学适配Principles and medical adaptation

设计原理Design principles

  • 将分割重写为固定数量 query 对 mask 的集合预测，而不是逐像素独立分类。Core Hypothesis: Formulate all segmentation tasks as mask-classification set prediction using learnable object queries and masked cross-attention. E0
  • masked attention 用上一轮 mask 把 cross-attention 限制在候选区域，既提高效率又强化局部一致性。Architectural Delta: Multi-scale high-resolution pixel decoder + masked cross-attention attending strictly within each query's predicted foreground region. E0
  • 同一 class+mask 接口通过不同组合规则覆盖语义、实例和全景分割。Mathematical Formalism: Mask-Constrained Cross-Attention Restricted to Predicted Foreground Regions. E0

医学边界Medical scope

  • query 集合适合多病灶、多器官和相互重叠实例，但小样本下需要处理 no-object 比例和匹配稳定性。Clinical Translation: Inspires unified multi-instance nuclei, lesion, and open-vocabulary query segmentation in pathology and radiology. E0
  • 医学三维化的主要成本在多尺度 voxel features 与 decoder attention；可把 query 作为器官/病灶候选而非类别硬编码。Evidence & Safety Boundary: Influential universal task interface; 3D memory scaling, tiny lesions, and bipartite matching stability remain challenging. E0
