RadFM

RadFM 的模型特异性在于统一 2D/3D 视觉 encoder 与 Perceiver 扫描聚合，再接生成式 LLM。Unifies 2D radiographs and 3D volumetric scans (CT/MRI) via a 2D/3D ViT + Perceiver 3D aggregator feeding into a generative radiology LLM. E0

01 / 上一代瓶颈Prior limitation

多数医学 VLM 只支持单张 2D 图像且任务和模态碎片化Most medical MLLMs accepted only single 2D slices, failing to ingest volumetric 3D CT/MRI studies natively.

02 / 核心想法Core idea

统一编码 2D 图像、3D 体积和文本，并以自回归 LLM 完成放射学多任务Encode both 2D images and 3D volumetric patches into unified visual tokens compressed by a Perceiver resampler before an autoregressive LLM.

设计原理Design principles

  • 视觉 encoder 同时容纳 2D 与 3D 扫描，而不是为每个模态建立孤立系统。Core Hypothesis: Encode both 2D images and 3D volumetric patches into unified visual tokens compressed by a Perceiver resampler before an autoregressive LLM. E0
  • Perceiver 将跨切片、跨时间或跨模态的可变长度特征压成固定 token。Architectural Delta: Unified 2D/3D visual tokenization + RadMD 16M multi-modal radiology instruction dataset + RadBench evaluation. E0
  • 用 LLM 把识别、问答和报告统一为条件文本生成。Mathematical Formalism: Unified 2D/3D Visual Token Perceiver Aggregation for Generative Radiology LLM. E0

医学边界Medical scope

  • 能在 CT、MRI、X-ray 等混合任务间共享视觉语言接口。Clinical Translation: Addresses multi-modality radiology VQA, report generation, and disease triage across X-ray, CT, and MRI. E0
  • 固定 token 压缩可能丢失微小三维病灶，且生成正确性不能由语言流畅度替代。Evidence & Safety Boundary: Important 3D-capable radiology MLLM proof-of-concept; hallucination rates and external clinical calibration remain critical hurdles. E0
