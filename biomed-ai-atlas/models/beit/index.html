BEiT

BEiT 的辨识点是预测外部 tokenizer 产生的离散视觉码，而非 MAE 式像素重建或普通对比学习。Pretrains Vision Transformers via BERT-style Masked Image Modeling by predicting discrete visual tokens generated by an external dVAE tokenizer. E0

01 / 上一代瓶颈Prior limitation

监督预训练依赖标签，早期图像 SSL 难直接复用 BERT 的 masked objectiveDirectly regressing raw RGB pixel values in BERT-style masked pretraining wasted model capacity on high-frequency local noise.

02 / 核心想法Core idea

把图像 patch 映射为离散视觉 token，随机遮挡后预测 tokenizer 码Quantize image patches into discrete visual tokens via a discrete VAE, then train a ViT to predict the hidden token IDs of masked patches.

原理与医学适配Principles and medical adaptation

设计原理Design principles

  • 把图像 patch 当作视觉词元，学习类似 BERT 的双向上下文。Core Hypothesis: Quantize image patches into discrete visual tokens via a discrete VAE, then train a ViT to predict the hidden token IDs of masked patches. E0
  • 监督目标来自独立离散 tokenizer，不是直接回归像素。Architectural Delta: Decouples continuous pixel array into a continuous patch embedding input view and a discrete semantic token target view. E0
  • 损失只计算被遮挡位置，预训练后保留 encoder 做下游迁移。Mathematical Formalism: Masked Patch Prediction Over Discrete Visual Codebook Tokens. E0

医学边界Medical scope

  • 可在大量无标注 CT、MRI、病理 patch 上学习上下文表示，再接医学任务头。Clinical Translation: Directly inspired HeartBEiT (12-lead ECG) and LaBraM (neural VQ tokenizer for EEG) biomedical foundation pretraining. E0
  • 若离散 tokenizer 未在医学域训练，微小病灶与定量灰度可能被量化目标忽略。Evidence & Safety Boundary: Pioneering MIM milestone; offline tokenizer training is often simplified by MAE pixel regression or iBOT online teachers. E0
