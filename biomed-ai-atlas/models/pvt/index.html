01 / 上一代瓶颈Prior limitation

平坦 ViT 保持固定 token 尺度，密集预测计算高且缺多尺度层级Columnar ViTs output single-scale low-resolution feature maps unsuitable for FPN/U-Net style dense prediction.

02 / 核心想法Core idea

逐级降低 token 分辨率并增加通道，形成 Transformer 金字塔Progressively shrink patch stride across four stages while spatially downsampling Key and Value tensors inside self-attention.

03 / 医学适配Medical adaptation

适配医学检测、分割和高分辨率病理特征金字塔Frequently used as a drop-in hierarchical Transformer encoder for polyp, skin lesion, and ultrasound segmentation.

原理与医学适配Principles and medical adaptation

设计原理Design principles

  • 通过 stage-wise token 下采样建立与 CNN 类似的分辨率金字塔，适配检测和分割。Core Hypothesis: Progressively shrink patch stride across four stages while spatially downsampling Key and Value tensors inside self-attention. E0
  • SRA 仅压缩 K/V 的空间长度，显著降低高分辨率 self-attention 计算。Architectural Delta: Pyramid token shrinking + Spatial-Reduction Attention (SRA) reducing attention memory and compute on high-resolution grids. E0
  • PVT-v1 仍使用位置编码和非重叠 patch embedding；不应把后续 PVTv2 的 overlap/卷积 FFN 混入。Mathematical Formalism: Spatial-Reduction Attention (SRA) for Multi-Scale Pyramid Tokens. E0

医学边界Medical scope

  • 适合高分辨病理、内镜和 2D 医学检测/分割中需要多尺度特征的任务。Clinical Translation: Frequently used as a drop-in hierarchical Transformer encoder for polyp, skin lesion, and ultrasound segmentation. E0
  • 小病灶可能在早期 patch 化或 SRA 中受损；3D 扩展还需重新设计 token 长度与内存。Evidence & Safety Boundary: Pioneered pyramid Vision Transformers; often succeeded by Swin or SegFormer (MiT) in recent pipelines. E0
