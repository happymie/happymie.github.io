01 / 上一代瓶颈Prior limitation

纯 L1/L2 输出过平滑，普通 GAN 不保证输入输出对应Pure L1/L2 regression blurs high-frequency textures, while unconditional GANs do not preserve patient-specific spatial anatomy.

02 / 核心想法Core idea

以输入为条件训练 PatchGAN，并以 L1 保持配对结构Condition both U-Net generator and patch-level discriminator on the input image x while anchoring low-frequency structure via L1 loss.

03 / 医学适配Medical adaptation

用于 paired 低剂量、PET、MR-CT 和骨抑制映射Workhorse baseline for paired low-dose-to-full-dose PET/CT, MR-to-synthetic-CT radiation planning, and virtual histological staining.

原理与医学适配Principles and medical adaptation

设计原理Design principles

  • conditional GAN 让判别器同时看 x 和输出，迫使真实性与给定输入相一致，而非任意生成。Core Hypothesis: Condition both U-Net generator and patch-level discriminator on the input image x while anchoring low-frequency structure via L1 loss. E0
  • PatchGAN 把判别学习限制在局部感受野，充当可学习的高频纹理损失并可卷积应用到任意尺寸。Architectural Delta: U-Net skip generator + 70×70 Markovian PatchGAN critic + λ||y − G(x)||_1 structural constraint. E0
  • U-Net skips 和 L1 保持配对结构，adversarial loss 弥补单纯像素回归造成的过度平滑。Mathematical Formalism: Conditional PatchGAN Adversarial Objective Coupled with Paired L1 Pixel Fidelity. E0

医学边界Medical scope

  • 适用于严格配准的低剂量→常规剂量、MR→CT 等 mapping；配准误差会被模型当作生成目标。Clinical Translation: Workhorse baseline for paired low-dose-to-full-dose PET/CT, MR-to-synthetic-CT radiation planning, and virtual histological staining. E0
  • Patch 级真实感不能保证器官拓扑或定量测量一致，必须检查病灶保真和物理/临床约束。Evidence & Safety Boundary: Strong paired image-translation baseline; remains an image-domain mapping without physical sensor consistency guarantees. E0
