DDPM

预设离散高斯前向链，加训练稳定的 epsilon/score 网络，再按学习到的随机逆链逐步采样。Defines a fixed discrete Markov Gaussian forward noising chain and trains a noise-prediction U-Net (ε_θ) across all noise scales for iterative reverse sampling. E0

01 / 上一代瓶颈Prior limitation

GAN min-max 训练不稳、mode coverage 差，VAE 高频模糊GANs suffered from adversarial instability and mode dropping, while likelihood-based flows and VAEs struggled with sample sharpness.

02 / 核心想法Core idea

通过逐步高斯加噪并训练网络在各噪声尺度预测噪声来生成数据Destroy data structure gradually via a fixed Gaussian diffusion process and learn the reverse Markov transition via stable multi-scale L2 noise regression.

原理与医学适配Principles and medical adaptation

设计原理Design principles

  • 固定前向高斯链把复杂数据分布平滑到简单噪声，学习任务被分解为多个噪声尺度的回归。Core Hypothesis: Destroy data structure gradually via a fixed Gaussian diffusion process and learn the reverse Markov transition via stable multi-scale L2 noise regression. E0
  • 噪声预测与 score 估计只差已知尺度因子，因此可用于构造逆向生成动力学。Architectural Delta: Re-weighted ε-prediction objective + time-conditioned U-Net achieving stable optimization and high mode coverage. E0
  • 原始高质量来自细粒度随机逆链，代价是大量网络评估；ODE 不是原论文的主采样路径。Mathematical Formalism: Closed-Form Forward Gaussian Marginals & Noise-Prediction Variational Bound Simplification. E0

医学边界Medical scope

  • 是医学图像合成、重建先验、去噪和跨模态生成的基础，但部署延迟通常需要加速采样器。Clinical Translation: Foundational prior for medical image synthesis, counterfactual generation, denoising, and diffusion-based inverse problem solvers. E0
  • 生成质量不能证明患者级事实保真；罕见病灶、设备域移位和不确定性校准需独立验证。Evidence & Safety Boundary: Core generative infrastructure; standard 1,000-step ancestral sampling is too slow for real-time clinical workflows without acceleration. E0
