Florence-2

核心不是增加多个 head，而是用任务提示和位置 token 将 caption、检测、grounding、分割全部改写为 seq2seq。Reformulates captioning, object detection, phrase grounding, and segmentation into a single prompt-driven sequence-to-sequence generation task with quantized coordinate tokens. E0

01 / 上一代瓶颈Prior limitation

视觉任务通常需要不同 head、标签格式和专用模型Multi-task vision systems required separate specialized task heads, loss functions, and architectural branches for boxes, masks, and text.

02 / 核心想法Core idea

把检测、分割、描述与定位统一为基于提示的序列到序列任务Represent spatial coordinates as discrete vocabulary tokens (1,000 bins) so a single DaViT + seq2seq Transformer handles all vision tasks.

03 / 医学适配Medical adaptation

可作为医学 VLM 的通用视觉接口和弱标注工具，但需领域适配Offers a unified promptable foundation interface adaptable to medical lesion detection, grounded reporting, and polygon annotation.

原理与医学适配Principles and medical adaptation

设计原理Design principles

  • 把多种视觉任务统一为由提示条件化的序列生成。Core Hypothesis: Represent spatial coordinates as discrete vocabulary tokens (1,000 bins) so a single DaViT + seq2seq Transformer handles all vision tasks. E0
  • 视觉 token 与文本提示在 encoder 中融合，decoder 不依赖任务专属检测或分割头。Architectural Delta: Unified coordinate-token sequence interface + FLD-5B (5.4B multi-task annotations across 126M images) unified pretraining. E0
  • 坐标量化为词表 token，使文本与空间输出共享交叉熵目标。Mathematical Formalism: Unified Task-Prompted Sequence-to-Sequence Generation Over Text & Coordinate Tokens. E0

医学边界Medical scope

  • 可作为医学弱标注接口，把同一影像转成描述、框或区域草案。Clinical Translation: Offers a unified promptable foundation interface adaptable to medical lesion detection, grounded reporting, and polygon annotation. E0
  • 自然图像位置词表与训练分布不保证微小病灶或 3D 体积定位准确，需领域微调和逐任务校准。Evidence & Safety Boundary: Frontier generalist vision interface; clinical precision on sub-millimeter boundaries and 3D volumes requires dedicated adaptation. E0
