01 / 上一代瓶颈Prior limitation

端到端训练大型视觉语言模型成本过高End-to-end joint pretraining of giant vision encoders and multi-billion-parameter LLMs was computationally prohibitive.

02 / 核心想法Core idea

冻结视觉 encoder 与 LLM，只训练 Q-Former 连接视觉查询和语言空间Keep both the vision encoder and LLM frozen, training only a lightweight Q-Former bottleneck to extract language-informative visual features.

成为最有影响力的 connector-based 医学 MLLM、VQA 和报告生成模板之一Canonical connector architecture behind medical VQA, report generation, and multimodal LLM assistants.

原理与医学适配Principles and medical adaptation

设计原理Design principles

  • Q-Former 用少量 learnable queries 从密集视觉 tokens 中抽取与文本最相关的信息，形成窄接口。Core Hypothesis: Keep both the vision encoder and LLM frozen, training only a lightweight Q-Former bottleneck to extract language-informative visual features. E0
  • 视觉 encoder 与 LLM 均冻结，把训练成本和灾难性遗忘集中到轻量跨模态桥。Architectural Delta: Two-stage pretraining: Stage 1 vision–language representation learning (ITC + ITM + ITG) followed by Stage 2 vision-to-LLM generative alignment. E0
  • 先做视觉语言表征对齐，再做面向 LLM 的生成对齐，分阶段解决模态差异与语言接口差异。Mathematical Formalism: Learnable Q-Former Queries Extracting Text-Relevant Visual Tokens for a Frozen LLM. E0

医学边界Medical scope

  • 可将冻结医学图像主干接入领域 LLM，但固定 query 数可能压缩掉多病灶或三维细节。Clinical Translation: Canonical connector architecture behind medical VQA, report generation, and multimodal LLM assistants. E0
  • 生成流畅度来自 LLM，不等于影像事实正确；需要定位证据、否定识别和幻觉审计。Evidence & Safety Boundary: Highly influential modular paradigm; strong frozen LLM priors can still hallucinate plausible text detached from visual query tokens. E0
