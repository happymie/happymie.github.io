LSTM

带门控的加性 cell memory 与 recurrent hidden state 分离，使长期信息可选择性保留和读出。Separates an additive linear cell memory state c_t (governed by forget and input gates) from the non-linear recurrent hidden state h_t to preserve long-term temporal gradients. E0

01 / 上一代瓶颈Prior limitation

vanilla RNN 长依赖中梯度消失或爆炸Vanilla RNNs multiplied recurrent weight matrices repeatedly across time, causing gradients to vanish or explode over >20 steps.

02 / 核心想法Core idea

用 cell state 和 input/forget/output gates 保留长期信息Introduce a linear self-connected memory cell c_t regulated by multiplicative sigmoid input, forget, and output gates.

03 / 医学适配Medical adaptation

长期用于小中型 ECG、EEG、EMG 与纵向临床序列Long-standing workhorse for 12-lead ECG arrhythmia classification, ICU vitals early-warning scores, and irregular EHR trajectories.

原理与医学适配Principles and medical adaptation

设计原理Design principles

  • 加性 cell-state 通路让误差信号跨较长时间传播，缓解普通 RNN 的梯度消失。Core Hypothesis: Introduce a linear self-connected memory cell c_t regulated by multiplicative sigmoid input, forget, and output gates. E0
  • 输入、遗忘与输出门按当前输入和历史状态选择写入、保留和读出内容。Architectural Delta: Additive cell-state highway enabling gradient propagation across hundreds of time steps. E0
  • 1997 原始 LSTM 强调 constant-error memory 与 input/output gates；现代标准 forget gate 是后续扩展，不应混作同年原始细节。Mathematical Formalism: Gated Additive Constant Error Carousel Cell Update: c_t = f_t ⊙ c_{t-1} + i_t ⊙ c̃_t. E0

医学边界Medical scope

  • 在中小数据的 ECG、EEG、EMG 和纵向表格序列上仍是可靠、易解释的基线。Clinical Translation: Long-standing workhorse for 12-lead ECG arrhythmia classification, ICU vitals early-warning scores, and irregular EHR trajectories. E0
  • 串行递归限制长记录吞吐，缺失模式、采样不规则和跨患者状态初始化需显式处理。Evidence & Safety Boundary: Reliable low-data sequential baseline; sequential step-by-step recurrence prevents parallel training across ultra-long multi-thousand-sample waveforms. E0
