  1. 01

    前向计算分数与概率Compute score and probability

    z=0.5×2−1=0，因此 sigmoid(z)=0.5。真值为 1，这个样本的损失是 −ln(0.5)=0.6931。z=0.5×2−1=0, so sigmoid(z)=0.5. Since the target is 1, the example loss is −ln(0.5)=0.6931.

    z=0; p=0.5; L=0.693147…
  2. 02

    先求损失对分数的导数Differentiate loss with respect to the score

    sigmoid 与二元交叉熵组合后，∂L/∂z=p−y=−0.5。负号表示增加当前分数会降低损失；它不是最终参数梯度。For sigmoid combined with binary cross-entropy, ∂L/∂z=p−y=−0.5. The negative sign means increasing this score reduces loss; it is not yet the parameter gradient.

    ∂L/∂z = p−y = −0.5
  3. 03

    沿链式法则分配到参数Apply the chain rule to parameters

    因为 ∂z/∂w=x=2、∂z/∂b=1，所以权重梯度为 −1，偏置梯度为 −0.5。把输入缩放一倍会改变权重梯度，却不直接改变偏置的局部导数。Because ∂z/∂w=x=2 and ∂z/∂b=1, the weight gradient is −1 and the bias gradient is −0.5. Doubling the input changes the weight gradient but not the local derivative for the bias.

    ∂L/∂w=−1; ∂L/∂b=−0.5
  4. 04

    用同一组旧参数同时更新Update both parameters from the same old state

    w′=0.5−0.1×(−1)=0.6；b′=−1−0.1×(−0.5)=−0.95。两个梯度都来自旧参数，不能更新 w 后重新计算 b 的梯度。w′=0.5−0.1×(−1)=0.6 and b′=−1−0.1×(−0.5)=−0.95. Both gradients come from the old parameter state; do not recompute the bias gradient after updating w.

    w′=0.6; b′=−0.95
  5. 05

    重新前向验证，而不是假定改善Verify with another forward pass

    新分数 z′=0.25，新概率 0.5622，新损失 0.5759。这个样本的损失确实下降；这不能推出未见患者上的效果也改善。The new score is z′=0.25, probability 0.5622, and loss 0.5759. Loss on this example falls; that does not establish improvement on unseen patients.

    p′=σ(0.25)=0.562176…; L′=0.575939…

不调用自动求导，用中心差分检查 w 与 b 的梯度；然后将 y 改为 0，重复一次更新。Without automatic differentiation, check both gradients with central differences. Then change y to 0 and repeat one update.

应该核对什么What to verify

  • 差分步长 10⁻⁵ 时，应得到约 −1 与 −0.5。A finite-difference step of 10⁻⁵ should give approximately −1 and −0.5.
  • 当 y=0 时，更新后 w=0.4、b=−1.05、z=−0.25。For y=0, updated parameters are w=0.4, b=−1.05, and z=−0.25.
  • 保留更新前与更新后的损失，核对方向与标签一致。Store before-and-after loss and confirm the update direction matches the target.

这一课要理解什么What you will understand

能区分数值预测与概率预测，解释平方损失和二元交叉熵怎样引导训练。Distinguish numerical from probabilistic prediction and explain how squared loss and binary cross-entropy guide training.

线性模型把特征加权相加A linear model combines weighted features

线性回归把输入特征乘以权重，再加偏置，得到一个数值预测。权重的意义取决于特征单位与其他特征，例如年龄按“年”还是“月”记录，会改变对应系数的数值。最小二乘通过减少预测与目标的平方差拟合参数，大误差会被更重地惩罚。线性指的是对参数的形式；输入也可以包含预先构造的平方项。先建立这样的基线，能检查数据是否提供有效信号，并给复杂网络一个有意义的参照。Linear regression multiplies features by weights, adds a bias and returns a numerical prediction. A coefficient depends on feature units and the other included features: recording age in years rather than months changes its numerical value. Least squares fits parameters by minimizing squared prediction errors, giving larger errors greater influence. “Linear” refers to the parameterization; inputs can include constructed features such as squared terms. A simple baseline helps establish whether the available data contains useful predictive signal and provides a meaningful comparison for a complex neural network.

逻辑回归输出概率Logistic regression produces a probability

二分类逻辑回归先计算线性分数 z，再用 sigmoid 把它映射到零到一之间。z 可以理解为模型的对数优势；z 为零时，输出为 0.5。概率与最终类别是两个层次：把阈值设为 0.5 只是常见选择，不是所有医学场景的最佳决策。改变阈值可以改变敏感度和特异度，但不会重新训练特征权重。多类别互斥任务常使用 softmax；多标签任务则需要分别定义每个标签的概率。Binary logistic regression first computes a linear score z, then uses a sigmoid to map it into the interval from zero to one. The score represents model log-odds; z=0 gives probability 0.5. A probability and a final class decision are different objects. A threshold of 0.5 is conventional, not automatically appropriate for every clinical setting. Changing the threshold trades sensitivity against specificity without retraining feature weights. Mutually exclusive multiclass tasks commonly use softmax, whereas multilabel tasks require a separate probability interpretation for each label.

损失是训练时的优化目标Loss is the objective used in training

二元交叉熵会惩罚对错误类别给出高概率的预测。目标为阳性时，概率越接近一，损失越小；接近零则损失很大。它与最终报告的准确率不是同一东西：准确率只关心过没过阈值，而交叉熵还关心概率。实际代码常直接把未归一化分数交给带 logits 的损失函数，以得到稳定计算，避免先 sigmoid 后再次处理。损失、采样权重和标签编码要一起核对，否则即使曲线下降，也可能在优化错误任务。Binary cross-entropy penalizes confident predictions of the wrong class. For a positive target, a probability near one has low loss, while a probability near zero has high loss. This differs from accuracy, which only checks whether a prediction crosses a threshold. Cross-entropy also evaluates the assigned probability. Implementations often pass raw scores directly to a logits-based loss for numerical stability, rather than applying sigmoid twice. Check the loss together with sampling weights and label encoding: a decreasing curve can otherwise mean the system is successfully optimizing the wrong task.

x 是特征，w、b 是参数，y∈{0,1} 是目标；交叉熵评价预测概率 p 对实际标签的支持程度。x contains features, w and b are parameters and y∈{0,1} is the target. Cross-entropy evaluates the probability p assigned to the observed label.

从分数到概率From a score to a probability

若一个特征 x=2，权重 w=0.5，偏置 b=−1，则 z=wx+b=0，sigmoid(z)=0.5。对真实阳性样本，二元交叉熵为 −log(0.5)，约 0.693。这个例子只展示模型计算。For one feature x=2, weight w=0.5 and bias b=−1, the score is z=wx+b=0 and sigmoid(z)=0.5. For a positive target, binary cross-entropy is −log(0.5), approximately 0.693. This is a calculation example, not an empirical model result.
