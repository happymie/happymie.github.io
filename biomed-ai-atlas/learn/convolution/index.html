九次乘法，读懂一个卷积响应Understand one convolution response through nine products

以下数量均为构造的教学条件。每一步都可以用纸笔或简短程序独立复核。All quantities below are constructed teaching conditions. Verify each step independently by hand or with a short program.

  1. 01

    先写有效窗口的尺寸Find the valid output size

    输入与核都是 3×3，无填充时只有一个完整窗口；输出空间长度为 (3−3)/1+1=1。不能把核中九个系数误当成九个输出。Input and kernel are both 3×3, so without padding there is only one complete window. Output size is (3−3)/1+1=1. Nine kernel coefficients do not mean nine outputs.

    Hout=Wout=1
  2. 02

    逐元素相乘再求和Multiply corresponding entries and sum

    九个乘积为 [1,0,0; 0,0,−3; 2,0,−1]。三行分别求和得到 1、−3、1，总响应为 −1。这个核比较左侧列与右侧列，而不直接关心中间列。The nine products are [1,0,0; 0,0,−3; 2,0,−1]. Row sums are 1, −3, and 1, yielding −1. This kernel compares the left and right columns rather than directly using the middle column.

    z = (1−0)+(0−3)+(2−1) = −1
  3. 03

    区分线性响应与非线性输出Separate the linear response and nonlinear output

    如果随后应用 ReLU，输出变为 0；原始响应 −1 的方向信息已经被该非线性抑制。核旋转 180° 后响应为 +1，因此应明确库采用卷积还是互相关约定。A following ReLU changes the output to 0, suppressing the direction information in −1. Flipping the kernel by 180° gives +1, so the convolution versus cross-correlation convention must be explicit.

    ReLU(−1)=0
  4. 04

    加入多通道与参数共享Add channels and shared parameters

    若输入有 2 个通道、输出有 4 个通道，每个输出通道需要一组 2×3×3 系数。总权重 72，另加 4 个偏置，合计 76；同一组系数会在所有空间位置复用。With 2 input channels and 4 output channels, each output channel needs 2×3×3 coefficients. There are 72 weights plus 4 biases, totaling 76. The same coefficients are reused at every spatial location.

    |θ| = 4×2×3×3+4 = 76
  5. 05

    再读步长与填充Then read stride and padding

    若给原始 3×3 输入四周补一圈零，其他条件不变，输出恢复为 3×3；边缘窗口使用了人为补入的值。因此边界响应也受填充规则影响。Adding a one-pixel zero border to the original 3×3 input produces a 3×3 output with the other settings unchanged. Border windows use artificial values, so boundary responses depend on the padding rule.

    Hout = (3+2×1−3)/1+1 = 3
亲手复现Reproduce it yourself

改变一个条件，再检查结果Change one condition and verify the result

先编写不依赖深度学习库的双重窗口循环，复现中心响应，再分别旋转核、交换左右列、将输入整体加 10。Write a window loop without a deep-learning library. Reproduce the response, then flip the kernel, swap the left and right columns, and add 10 to every input value.

应该核对什么What to verify

  • 默认响应 −1，旋转核或交换左右列后响应 +1。The default response is −1; flipping the kernel or swapping side columns gives +1.
  • 所有输入都加 10 后响应仍为 −1，因为核系数之和为零。Adding 10 to every input leaves the response −1 because the kernel coefficients sum to zero.
  • 分别保存 ReLU 前与后的值，验证负响应确实在非线性处消失。Save values before and after ReLU to verify where the negative response disappears.

这一课要理解什么What you will understand

能解释权重共享，计算输出尺寸，并区分理论感受野与实际信息贡献。Explain weight sharing, calculate output size and distinguish theoretical receptive field from actual information contribution.

一个核，在不同位置重复使用One kernel reused across positions

卷积层让小窗口在输入上滑动，每个位置使用同一组可学习权重计算输出。深度学习库通常执行不翻转核的互相关，但沿用“卷积”名称。权重共享降低参数需求，并利用局部模式可在不同位置出现的假设。单个输出通道会汇总所有输入通道的贡献，不只是处理某一种颜色。多个核形成多个特征图，经非线性后再交给下一层；边缘、纹理或更复杂表示，都是训练目标和数据共同塑造的结果。A convolutional layer slides a small window over the input, applying the same learned weights at every position. Deep-learning libraries generally implement cross-correlation without flipping the kernel, while retaining the name convolution. Weight sharing reduces parameter requirements and encodes the assumption that local patterns may occur at different locations. One output channel combines contributions from all input channels; it is not restricted to one color. Multiple kernels produce feature maps, which pass through nonlinearities into later layers. Their learned representations depend on both the training data and objective.

步幅、填充与空洞决定采样Stride, padding and dilation control sampling

步幅决定窗口每次移动多少格；填充在边界补值，影响边缘处理与输出尺寸；空洞率让核元素之间留出间隔，以较少参数覆盖更大范围。它们改变的不是同一件事。下采样减少空间分辨率与计算量，也可能丢失细小目标。医学图像还要结合物理间距理解核的范围：相同的三层切片，在薄层和厚层扫描中覆盖的毫米数不同。设计二维或三维网络时，不能只看像素数量而忽略体素间距。Stride controls how far the window moves. Padding supplies boundary values and affects output size. Dilation inserts gaps between kernel elements, covering a wider region without adding the corresponding number of parameters. These operations serve different purposes. Downsampling lowers spatial resolution and computation but can lose small targets. For biomedical images, physical spacing also matters: three slices span different distances in thin- and thick-slice scans. Choosing a two- or three-dimensional architecture therefore requires considering voxel spacing and acquisition geometry, rather than only counting pixels or slices.

感受野怎样逐层扩大How receptive fields grow

某个输出位置的理论感受野，是沿计算图追溯后可能影响它的输入范围。两层步幅为一的 3×3 卷积，在没有空洞时得到 5×5 的理论感受野，而不是 6×6；重叠区域会共享。理论上可到达的输入，并不一定对结果贡献相同，实际梯度或信息贡献可能集中在其中一部分。U-Net 的下采样路径汇总上下文，跳连把较高分辨率特征送回解码器，兼顾定位和语义；这也解释了为什么要同时检查结构与空间尺寸。The theoretical receptive field of an output location is the range of input positions that could influence it through the computation graph. Two stride-one 3×3 convolutions without dilation yield a 5×5 receptive field, not 6×6, because their windows overlap. Potential reach does not imply equal contribution: gradients or useful information may concentrate within a smaller region. In U-Net, the contracting path aggregates context while skip connections return higher-resolution features to the decoder. Understanding this combination requires tracking both the architecture and its spatial dimensions.

关键公式The key equation

把机制写成公式THE MECHANISM IN AN EQUATION

O=⌊I+2p−d(k−1)−1s⌋+1O=\left\lfloor\frac{I+2p-d(k-1)-1}{s}\right\rfloor+1O=⌊sI+2p−d(k−1)−1​⌋+1

I、O 是单个空间轴的输入和输出长度，k 是核大小，p 是单侧填充，s 是步幅，d 是空洞率。I and O are the input and output lengths along one spatial axis; k is kernel size, p padding per side, s stride and d dilation.

计算一次输出尺寸Calculate an output size

输入宽度为 32，卷积核宽度 3，步幅 1，填充 0，空洞率 1，输出宽度为 30。若改为两侧各填充 1，输出宽度为 32。再增加输出通道会增加特征图数量，不会自动增加空间分辨率。For input width 32, kernel width 3, stride 1, padding 0 and dilation 1, output width is 30. Padding by one on each side produces width 32. Increasing output channels adds feature maps; it does not itself increase spatial resolution.

再想深一步Take the idea further

更大的理论感受野不等于模型一定利用了更远处的解剖关系；还要用实验检查。A larger theoretical receptive field does not establish that the model uses distant anatomical relationships. That requires empirical investigation.
