让每个轴与每一次乘法都有含义Give every axis and multiplication a meaning

以下数量均为构造的教学条件。每一步都可以用纸笔或简短程序独立复核。All quantities below are constructed teaching conditions. Verify each step independently by hand or with a short program.

先明确符号、数量与假设Define symbols, quantities, and assumptions
符号Symbol设定Setting含义与边界Meaning and assumptions
X2 × 3两个样本，每个样本三个特征。Two samples with three features each.
W3 × 2将三个输入特征映射到两个输出。Maps three input features to two outputs.
b[0.5, −0.5]同一偏置向量广播到两个样本。One bias vector is broadcast across the two samples.
N,C,H,W[2,1,4,4]另一个图像例子的轴顺序为批次、通道、高、宽。The image example uses batch, channel, height, width order.
  1. 01

    写出数组与轴Write arrays and axes

    令 X 的两行为 [1,2,0] 与 [−1,1,3]；W 的三行为 [1,0]、[0,2]、[1,−1]。内部长度同为 3，因此 XW 合法，输出形状为 2×2。Let X have rows [1,2,0] and [−1,1,3], and W have rows [1,0], [0,2], and [1,−1]. The shared inner dimension is 3, so XW is valid and has shape 2×2.

    (2×3)(3×2) → 2×2
  2. 02

    逐项手算矩阵乘法Calculate the matrix product

    第一个输出为 1×1+2×0+0×1=1；第二个为 1×0+2×2+0×(−1)=4。第二个样本得到 [2,−1]。每个输出都对特征轴求和，样本轴不参与求和。The first output is 1×1+2×0+0×1=1; the second is 1×0+2×2+0×(−1)=4. The second sample gives [2,−1]. Each output sums across features, not across samples.

    XW = [[1,4],[2,−1]]
  3. 03

    检查广播，而不增加新参数Check broadcasting without adding parameters

    给每一行加同一个 b，得到 [[1.5,3.5],[2.5,−1.5]]。偏置共有两个可学习参数，不是每个样本各拥有两个。该层参数量为 3×2+2=8。Adding the same b to each row gives [[1.5,3.5],[2.5,−1.5]]. There are two learnable bias parameters, not a separate pair for each sample. The layer has 3×2+2=8 parameters.

    Y = XW + b; |θ| = 8
  4. 04

    把同一规则应用到卷积形状Apply the rule to convolution shapes

    输入 [2,1,4,4]，三个 3×3 输出卷积核，步长 1、无填充时，空间长度为 (4−3)/1+1=2。输出是 [2,3,2,2]，总元素数 24；含偏置参数为 3×1×3×3+3=30。For input [2,1,4,4], three 3×3 output kernels, stride 1, and no padding, spatial size is (4−3)/1+1=2. Output shape is [2,3,2,2], containing 24 values. Parameters including bias total 3×1×3×3+3=30.

    [2,1,4,4] → [2,3,2,2]
  5. 05

    区分重塑与轴置换Distinguish reshape from axis permutation

    [[1,2],[3,4]] 转置后应为 [[1,3],[2,4]]；重塑成长度 4 的向量通常得到 [1,2,3,4]。元素个数相同不能证明轴语义相同。Transposing [[1,2],[3,4]] gives [[1,3],[2,4]], whereas reshaping it to length 4 ordinarily gives [1,2,3,4]. Equal element counts do not establish equal axis meanings.

  • 新卷积输出为 [5,3,2,2]，元素数 60，参数量仍为 30。The new convolution output is [5,3,2,2], with 60 values and still 30 parameters.

这一课要理解什么What you will understand

能解释批次、通道和空间轴，推导矩阵乘法与简单卷积的输入输出形状。Explain batch, channel and spatial axes, and derive shapes for matrix multiplication and a simple convolution.

先给每个轴命名Name every axis

标量是一个数，向量是一列有序数，矩阵有两个轴，张量可有更多轴。这里的“维度”要分清是轴的数量，还是某个轴的长度。一批二维医学图像常写为 N×C×H×W：N 是样本数，C 是通道数，H、W 是高与宽。三维体积再加入深度 D。相同数字可以有不同语义：三张单通道切片不一定等于一张三通道图像。阅读任何形状时，先写轴名，再解释每个数值。A scalar is a number, a vector is an ordered collection, a matrix has two axes and a tensor may have more. Distinguish the number of axes from the length of one axis. A batch of two-dimensional images is often stored as N×C×H×W: batch size, channels, height and width. A volume adds a depth axis. Equal numbers do not imply equal meanings: three grayscale slices are not necessarily one three-channel image. For every tensor, name its axes before interpreting its numerical shape.

形状约束就是计算约束Shapes constrain computation

矩阵乘法 XW 要求 X 的最后一轴与 W 的第一轴长度一致。若 X 是 8×10，W 是 10×4，结果就是 8×4，可理解为把八个样本的十个特征映射为四个输出。逐元素相乘则是另一种运算，不能与矩阵乘法混淆。改变形状也不等于改变信息组织：直接重排数组的尺寸，可能把通道与空间混在一起；交换轴应使用明确的转置或轴置换，并检查语义是否保留。For matrix multiplication XW, the inner dimensions must agree. If X has shape 8×10 and W has shape 10×4, the result has shape 8×4: ten features from each of eight samples become four outputs. Elementwise multiplication is a different operation. Reshaping also differs from rearranging axes. A reshape can silently mix the interpretation of spatial locations and channels if it is used where an axis permutation was needed. Write the intended axis order, use an explicit transpose or permutation, and check that each value retains its meaning.

把形状接回医学含义Connect shapes to biomedical meaning

分割模型常从 N×1×H×W 的灰度图输出 N×K×H×W 的类别分数，其中 K 是类别数，而不是图像数量。分类模型则可能输出 N×K，空间信息已经聚合。批次轴改变一次处理多少样本，通常不改变单个样本的任务定义。体积数据还需要体素间距：相同的 64×64×64 网格可能覆盖不同物理范围。张量形状说明计算布局，间距、方向和坐标系才说明它在真实身体中的位置。A segmentation model may map grayscale inputs of shape N×1×H×W to class scores of shape N×K×H×W. K is the number of classes, not the number of images. A classifier may instead return N×K after spatial aggregation. Changing the batch axis usually changes throughput rather than the task for an individual sample. Volumes also require voxel spacing: identical 64×64×64 arrays can cover different physical extents. Tensor shape specifies computational layout; spacing, orientation and coordinates specify the relationship to anatomy.

关键公式The key equation

把机制写成公式THE MECHANISM IN AN EQUATION

X∈RN×d,W∈Rd×k⇒XW∈RN×kX\in\mathbb{R}^{N\times d},\quad W\in\mathbb{R}^{d\times k}\quad\Rightarrow\quad XW\in\mathbb{R}^{N\times k}X∈RN×d,W∈Rd×k⇒XW∈RN×k

N 是样本数，d 是输入特征数，k 是输出特征数；内侧的 d 必须相同。N is the number of samples, d the input feature count and k the output feature count. The inner d dimensions must match.

读懂一个分割输出Read a segmentation output

输入为 4×1×256×256，输出为 4×3×256×256：四张单通道图像，每个像素有三个类别分数。若类别互斥，沿类别轴做 softmax；若目标可以重叠，应重新确认标签定义和输出激活。An input of 4×1×256×256 and output of 4×3×256×256 means four grayscale images with three class scores at each pixel. Mutually exclusive classes can use softmax across the class axis. Overlapping targets require a different label interpretation and possibly independent sigmoid outputs.

再想深一步Take the idea further

形状可以对得上，轴的语义仍可能错位；尺寸检查需要与通道、坐标和单位检查一起完成。Compatible numerical shapes can still hide incorrect axis meanings. Check channels, coordinates and units as well as dimensions.
