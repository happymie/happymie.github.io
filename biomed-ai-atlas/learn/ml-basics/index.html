  1. 01

    先写任务单位Define the prediction unit

    每个对象有一个输入和一个二元目标，因此输出应是四个分数，而不是逐像素掩码。标签均值为 2/4；不看输入的基线可以对所有对象输出 0.5。Each object has one input and one binary target, so the output is four scores rather than a pixel mask. The label mean is 2/4; an input-independent baseline can assign 0.5 to every object.

    p₀ = [0.5, 0.5, 0.5, 0.5]
  2. 02

    先把基线算清楚Calculate the baseline

    以二元交叉熵评价这些给定分数，每个对象的损失都是 −ln(0.5)，平均损失为 0.6931。阈值采用 ≥，四个对象都预测为阳性，错两个。Binary cross-entropy for each assigned score is −ln(0.5), giving mean loss 0.6931. With a ≥ threshold rule, all four are predicted positive and two are wrong.

    L₀ = −ln(0.5) = 0.6931
  3. 03

    比较一组明确给定的候选分数Compare an explicitly supplied candidate

    候选分数设为 [0.1, 0.2, 0.8, 0.9]。这是一组用于解释目标函数的给定数值，不是一次已完成训练的实验结果。四个正确类别的概率依次是 0.9、0.8、0.8、0.9。Assign candidate scores [0.1, 0.2, 0.8, 0.9]. These are supplied values for explaining an objective, not results from a claimed training experiment. Probabilities assigned to the correct classes are 0.9, 0.8, 0.8, and 0.9.

    L₁ = −(2ln(0.9) + 2ln(0.8))/4 = 0.1643
  4. 04

    分清决策与优化目标Separate decisions from the optimization objective

    阈值 0.5 得到 [0,0,1,1]，这四个对象上的错误数为零，但交叉熵仍大于零。分类是否正确只看分数在哪一侧；交叉熵还关心分给正确类别的概率。Thresholding at 0.5 gives [0,0,1,1], with zero errors on these four objects, while cross-entropy remains positive. Classification checks which side of the threshold a score lies on; cross-entropy also considers the probability assigned to the correct class.

    ŷ = [0, 0, 1, 1] ≠ p
  5. 05

    把学习方式接回目标来源Trace the source of supervision

    以上目标 y 由外部给定，属于监督问题。若目标改成补全被遮住的输入，目标来自原始数据本身；任务、损失及评价单位都要重新写明，而不是只把网络名称换掉。Here y is supplied externally, so this is supervised learning. If the target becomes a hidden part of the input, supervision comes from the original data. The task, loss, and evaluation unit must all be specified again; changing only the architecture name is insufficient.

这一课要理解什么What you will understand

能用输入、输出和学习信号描述一个医学 AI 问题，并区分主要学习方式。Describe a biomedical AI problem through its inputs, outputs and learning signal, and distinguish the main learning settings.

三个概念，三个层次Three concepts at different levels

人工智能关注让机器完成感知、推理、规划等任务；机器学习是其中一类方法，通过数据调整模型，而不是为每种情况手写规则。深度学习又是机器学习的一部分，用多层可学习变换逐步形成表示。例如，传统分类器可以读取人工测量的病灶直径，卷积网络则可以从像素学习局部纹理及其组合。层数多不直接等于能力强：任务定义、样本质量、训练目标与验证方式共同决定模型是否有用。Artificial intelligence concerns tasks such as perception, reasoning and planning. Machine learning is one way to build such systems: data adjusts a model instead of a programmer writing every decision rule. Deep learning is a form of machine learning that learns representations through multiple transformations. A conventional classifier might use a manually measured lesion diameter; a convolutional network can learn features from pixels. More layers do not automatically make a better system. The task, examples, training objective and evaluation design all contribute to whether a model is useful.

监督、无监督与自监督Supervised, unsupervised and self-supervised learning

监督学习使用输入与目标的配对，例如胸片和对应诊断标签，或图像和逐像素分割。无监督学习研究没有这类人工目标的数据结构，例如聚类和降维。自监督学习从数据本身构造训练目标：遮住图像块再重建，或让同一图像的两种视图得到相关表示。它通常归入无监督学习，但目标仍由人设计。预训练不使用疾病标签，并不代表下游预测不需要标签，也不代表训练数据中没有患者信息。Supervised learning uses paired inputs and targets, such as radiographs with diagnosis labels or images with segmentation masks. Unsupervised learning studies structure without those human-provided targets, for example through clustering or dimensionality reduction. Self-supervised learning constructs targets from the data itself: it may reconstruct hidden image patches or align two views of one image. It is commonly grouped with unsupervised learning, although people still design the objective. Pretraining without disease labels does not eliminate the need for downstream labels or remove patient information from the training data.

从临床问题写出学习任务Translate a clinical question into a learning task

把“识别疾病”改写成可检查的任务：输入是什么、在什么时间可获得、输出对应哪个对象、参考标准怎样得到。例如，输入一次检查的胸片，输出检查级阳性概率；这与给每个像素标记肺野是两个任务。还要写清适用人群、预测时间窗和评价单位。随后选择简单基线，再考虑复杂架构。如此阅读模型论文时，可以先问它解决了哪种输入到输出的映射，再问结构带来了什么改变。Turn a broad aim such as “detect disease” into a task that can be inspected. Specify the input, when it is available, the object receiving the prediction and how the reference standard is obtained. Predicting a positive probability for one radiographic examination differs from labeling each lung pixel. Also define the target population, prediction horizon and evaluation unit. Start with a simple baseline before selecting a complex architecture. When reading a paper, first identify its input-to-output mapping; then ask what the proposed architecture changes about that mapping.

同一张胸片，三种任务One radiograph, three tasks

预测是否存在某种异常是分类；估计病灶面积是回归；标记每个像素的病灶归属是分割。任务不同，目标张量、损失函数和指标也不同。Predicting whether an abnormality is present is classification; estimating lesion area is regression; assigning a lesion label to each pixel is segmentation. Each task requires a different target tensor, loss and evaluation metric.

再想深一步Take the idea further

“基础模型”描述预训练与迁移方式，不是“任何医学任务都能直接完成”的保证。“Foundation model” describes a pretraining and adaptation paradigm; it does not establish performance on every biomedical task.
