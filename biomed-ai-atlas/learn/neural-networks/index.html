从一个神经元到多层感知机From one neuron to a multilayer perceptron

人工神经元先对输入加权求和，再经过激活函数；早期感知机用阈值函数完成二分类。多层感知机把这样的单元组织为输入层、隐藏层和输出层，让中间表示也参与学习。关键不只是多加矩阵：如果各层只有线性或仿射变换，连续相乘仍可合并为一次仿射变换。隐藏层的非线性让网络能够表示弯曲或分段的关系。宽度描述一层有多少单元，深度描述变换的层次，二者共同影响表示能力和计算量。An artificial neuron forms a weighted sum of inputs and applies an activation. Early perceptrons used threshold functions for binary classification. A multilayer perceptron organizes units into input, hidden and output layers, making intermediate representations learnable. Adding matrices alone is not enough: a composition containing only linear or affine transformations can still be collapsed into one affine transformation. Nonlinear hidden layers let a network represent curved or piecewise relationships. Width describes the number of units in a layer; depth describes the sequence of transformations. Both affect representation capacity and computational cost.

前向计算：形状、激活与任务输出Forward computation: shapes, activations and task outputs

一次前向计算把输入逐层变成隐藏表示，再变成输出分数。ReLU 把负值置零并保留正值，提供简单的非线性；sigmoid 将数值压到零和一之间，常用于二分类输出，但在饱和区梯度较小。隐藏层激活与输出层激活承担不同职责：回归可以直接输出数值，互斥分类可以从分数计算 softmax，多标签分类则可分别计算 sigmoid。每一步都要同时核对轴、数值范围和目标定义，不能只看最终张量长度。A forward pass transforms an input into hidden representations and then output scores. ReLU sets negative values to zero and retains positive ones, providing a simple nonlinearity. Sigmoid maps values between zero and one and is useful for binary outputs, although its gradients become small in saturated regions. Hidden and output activations have different jobs. Regression may return numerical values directly; mutually exclusive classification can apply softmax to scores, while multilabel classification can use independent sigmoids. Check axis meanings, value ranges and target definitions at each step, not just the final output length.

归一化与训练、推理模式Normalization and training–inference modes

输入标准化使用训练数据确定尺度；网络内部的归一化层则处理隐藏表示，两者不是同一个步骤。常见 BatchNorm 在训练中按批次与空间位置统计各通道，并可维护滑动统计量；默认推理时使用保存的统计量。dropout 在训练中随机屏蔽激活，常规推理时关闭这种随机操作。因此评估前要切换模型模式。切换评估模式与关闭梯度记录也是两件事：前者改变这些层的行为，后者减少求导开销；正确推理通常需要把两者一起设置。Input standardization establishes scales using training data; normalization inside a network acts on hidden representations. They are different steps. Common BatchNorm implementations estimate channel statistics over batch and spatial positions during training and can maintain running estimates, which are used by default during inference. Dropout randomly suppresses activations in training and disables that sampling in ordinary inference. Switch the model to evaluation mode before assessment. Evaluation mode and disabling gradient recording are separate operations: one changes layer behavior, while the other avoids differentiation overhead. Correct inference commonly configures both.

关键公式The key equation

把机制写成公式THE MECHANISM IN AN EQUATION

h=σ(W1x+b1),y^=W2h+b2h=\sigma(W_1x+b_1),\qquad \hat y=W_2h+b_2h=σ(W1​x+b1​),y^​=W2​h+b2​

W₁、b₁ 和 W₂、b₂ 是两层参数，σ 是隐藏层激活；输出是否还需概率变换，由目标任务与损失决定。W₁, b₁ and W₂, b₂ are the two layers’ parameters; σ is the hidden activation. The task and loss determine whether the output needs a probability transformation.

手算一个两层网络Calculate a two-layer network

取输入 x=(1,−2)，第一层为单位矩阵且偏置为零。ReLU 后得到 h=(1,0)。第二层权重为 (2,−1)，偏置为 0.5，输出就是 2×1−1×0+0.5=2.5。若删去 ReLU，相同参数会输出 4.5；非线性改变了计算关系。Let x=(1,−2), the first-layer weight be the identity matrix and its bias be zero. ReLU produces h=(1,0). With second-layer weights (2,−1) and bias 0.5, the output is 2×1−1×0+0.5=2.5. Removing ReLU produces 4.5 with the same parameters, showing how the nonlinearity changes the mapping.
