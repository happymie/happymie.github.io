LSTM

带门控的加性 cell memory 与 recurrent hidden state 分离，使长期信息可选择性保留和读出。Separates an additive linear cell memory state c_t (governed by forget and input gates) from the non-linear recurrent hidden state h_t to preserve long-term temporal gradients.

Temporal Convolutional Network (TCN)

以因果、指数扩张的 1D 卷积残差块并行覆盖长历史，而不使用循环状态。Stacks 1D causal convolutions with exponentially increasing dilation factors d = 2^l inside residual blocks to cover long historical receptive fields in parallel.
