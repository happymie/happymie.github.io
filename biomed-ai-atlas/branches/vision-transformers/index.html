Transformer

无递归的多头 self-attention encoder 与 masked self-/cross-attention decoder。Recurrence-free multi-head self-attention encoder paired with a masked self- and cross-attention decoder.

2021 · ICLR

Vision Transformer (ViT)

非重叠 patch 线性 token 化、CLS 汇聚与全局 Transformer encoder，完全移除卷积主干。Splits images into non-overlapping patches, linearly projects them into tokens with positional embeddings, and processes them via a pure global Transformer encoder.

2021 · ICCV

Swin Transformer

W-MSA 与 SW-MSA 交替实现局部高效注意力和跨窗连接，并以 patch merging 形成层次金字塔。Alternates regular Windowed Multi-Head Self-Attention (W-MSA) with Shifted-Window Attention (SW-MSA) across a patch-merging multi-scale pyramid.

2021 · ICML

DeiT

增加 distillation token 和专用 head，使 CNN teacher 信号通过 Transformer attention 注入 ViT。Augments ViT with a learnable distillation token that interacts with patch tokens via self-attention to distill inductive biases from a CNN teacher.

2021 · ICCV

PVT

以逐级降低 token 分辨率的 Transformer pyramid 和 spatial-reduction attention 提供多尺度 dense-prediction backbone。Constructs a progressive four-stage token pyramid using Spatial-Reduction Attention (SRA) to compress K/V resolution before attention.
