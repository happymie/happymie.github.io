FBPConvNet

解析 FBP 与单次残差 U-Net 串联，而非端到端替代投影算子或进行 unrolled data consistency。Cascades analytical Filtered Backprojection (FBP) with a multi-scale residual U-Net in the image domain to remove sparse-view streaking artifacts.

2018 · IEEE Transactions on Medical Imaging

Learned Primal-Dual

同时学习 measurement-domain dual 与 image-domain primal 更新，并在每个 unrolled stage 显式调用 A 和 A*。Unrolls primal–dual proximal optimization into K stages of paired measurement-domain (dual) and image-domain (primal) residual CNNs calling A and A* at every stage.
物理约束医学重建Physics-Informed Recon＋
2018 · Magnetic Resonance in Medicine

Variational Network

把多线圈 MRI 的变分梯度下降展开，并联合学习卷积滤波器、势函数与每级更新权重。Unrolls K steps of gradient descent on a generalized Fields-of-Experts variational energy for multi-coil MRI, jointly learning convolutional filters, non-linear potentials, and data weights.
物理约束医学重建Physics-Informed Recon＋
2019 · IEEE Transactions on Medical Imaging

MoDL

共享 CNN prior 与可微共轭梯度 data-consistency 子问题交替展开。Alternates a weight-shared multi-layer CNN denoiser prior D_θ with a differentiable numerical Conjugate Gradient (CG) solver enforcing exact data consistency (A*A + λI)^{-1}.

2020 · MICCAI

VarNet

灵敏度估计网络加多级 k-space variational cascades，将图像正则与采样点 DC 工程化为统一流程。End-to-End Variational Network combining a joint U-Net coil sensitivity estimation module (SME) with K k-space variational cascades using U-Net image regularizers.

2018 · Nature

AUTOMAP

AUTOMAP 的标志是大规模全连接层直接承担 domain transform，而非先做 FBP/IFFT 再用 CNN 后处理。Learns the sensor-to-image domain transform directly via large fully connected layers mapping flattened raw measurements to an image grid followed by sparse convolutional refinement.

2018 · IEEE Transactions on Medical Imaging

LEARN

LEARN 每个展开阶段并行计算 CT 数据梯度和 learned experts CNN 正则梯度，再做残差更新。Unrolls K iterative sparse-view CT reconstruction stages where each stage combines an explicit projection residual gradient A^T(Ax^t − y) with a stage-specific 3-layer CNN regularizer.
