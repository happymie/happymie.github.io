pix2pix

以 U-Net 生成器保持逐像素空间对应，70×70 conditional PatchGAN 学局部真实感，并用配对 L1 锚定结构。Pairs a U-Net generator (preserving pixel-level spatial alignment) with a 70×70 conditional PatchGAN discriminator and paired L1 structural anchoring.

CycleGAN

双生成器、双 PatchGAN 与 X→Y→X / Y→X→Y 两个 cycle L1 闭环，使不成对域转换可训练。Couples dual generators (G: X→Y, F: Y→X) and dual PatchGAN discriminators with forward and backward L1 cycle-consistency loops for unpaired translation.

DDPM

预设离散高斯前向链，加训练稳定的 epsilon/score 网络，再按学习到的随机逆链逐步采样。Defines a fixed discrete Markov Gaussian forward noising chain and trains a noise-prediction U-Net (ε_θ) across all noise scales for iterative reverse sampling.

DDIM

在相同 DDPM 训练边缘下采用隐式非 Markov、可确定性的跳步轨迹。Constructs non-Markovian, deterministic reverse sampling trajectories that share the exact same marginal training distributions as DDPM.

Score-SDE

以连续 score field 同时定义 reverse-time SDE、predictor-corrector sampler 与同边缘的 probability-flow ODE。Unifies discrete diffusion and score matching into a continuous-time Stochastic Differential Equation (SDE) with a corresponding deterministic Probability-Flow ODE.

Latent Diffusion

先以 autoencoder 压缩图像，再在 latent grid 上运行可 cross-attention 条件化的 diffusion。Perceptually compresses high-resolution images into a lower-dimensional spatial latent grid via a VQ/KL autoencoder before running cross-attention-conditioned diffusion.

DDRM

在退化算子 SVD 基中把预训练 diffusion prior 与线性观测条件分量逐时间步耦合。Couples an unconditional pretrained diffusion prior with a linear forward operator y = Hx + z by running conditional reverse diffusion in the SVD spectral domain of H.

DPS

在每个 diffusion 逆时间步，把预训练先验 score 与经 x0 估计反传的测量 likelihood gradient 相加。Approximates intractable time-dependent measurement likelihood scores ∇_{x_t} log p_t(y|x_t) via backpropagation through the Tweedie posterior mean estimate x̂_0(x_t).

DiffusionMBIR

把预训练 2D diffusion slice prior 嵌入 3D MBIR/data-consistency 外循环，并显式加跨切片约束。Embeds a pretrained 2D slice diffusion score prior into an alternating 3D Model-Based Iterative Reconstruction (MBIR) loop with explicit z-axis total variation regularization.

Flow Matching

在已知 probability path 上回归 velocity（而非 score），再直接积分神经 ODE 完成分布运输。Trains continuous normalizing flows without ODE simulation by directly regressing the marginal vector field u_t(x) along conditional probability paths.

Rectified Flow

以直线端点路径训练 velocity，并通过 reflow 重新耦合端点以进一步拉直 ODE 轨迹。Learns an ODE velocity field along straight linear interpolations x_t = (1−t)x_0 + t x_1 and iteratively straightens trajectories via reflow recoupling.

Consistency Models

学习沿 PF-ODE 轨迹不变的 endpoint map，使任意噪声尺度可直接一步映射到 clean sample。Learns a self-consistent function f_θ(x_t, t) = x_ε that maps any point along a Probability-Flow ODE trajectory directly to its clean origin in a single step.

DiT

把 noisy latent patch 化，以 adaLN-Zero 条件化的 Transformer blocks 作为 diffusion score/velocity backbone。Replaces the convolutional U-Net backbone in Latent Diffusion with an isotropic Vision Transformer over latent patches conditioned via Adaptive LayerNorm-Zero (adaLN-Zero).

DDNM

DDNM 用 A†y 固定 range-space 信息，只让 diffusion denoiser 生成 null-space 分量。Decomposes reverse diffusion intermediate estimates x̂_{0|t} via the Moore–Penrose pseudoinverse A† into a fixed measurement range-space component A†y and a generated null-space component (I − A†A)x̂_{0|t}.

RealNVP

RealNVP 以三角 Jacobian 的 affine coupling 获得同时精确可逆、可采样且可算 log-likelihood 的映射。Constructs an exactly invertible normalizing flow using stacked affine coupling layers whose triangular Jacobians permit O(D) log-determinant and exact likelihood evaluation.

Glow

PFGM++

PFGM++ 用可调增广维度 D 的 Poisson 电场统一 PFGM 与 diffusion，而不是固定高斯前向噪声过程。Embeds N-dimensional data on the z=0 hyperplane of an N+D augmented space and learns the high-dimensional Poisson electric field lines, unifying PFGM (D=1) and Diffusion (D→∞).
