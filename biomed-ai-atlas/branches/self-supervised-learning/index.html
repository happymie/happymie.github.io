SimCLR

无动量教师或队列，以大 batch 内的两视图实例对和非线性投影头训练 NT-Xent。Trains an encoder and non-linear MLP projection head via in-batch NT-Xent contrastive loss across dual augmented views without momentum queues.

2020 · CVPR

MoCo

由 EMA key encoder 维护一致编码、由 FIFO queue 提供大规模跨 batch 负样本的对比字典。Decouples contrastive negative dictionary size from mini-batch size using a FIFO queue of encoded keys updated via a momentum (EMA) encoder.

2022 · CVPR

MAE

高比例随机遮蔽后仅编码可见 patch，再用轻量 decoder 重建 mask patch 的非对称自编码器。Asymmetric autoencoder that masks 75% of image patches, encodes only the 25% visible tokens with a heavy ViT, and reconstructs pixels via a lightweight decoder.

2021 · ICCV

DINO

无负样本的 EMA teacher–student 跨视图概率匹配，以 centering 与 sharpening 防止塌缩。Negative-free self-distillation where a student ViT matches the centered, temperature-sharpened probability distribution of an EMA teacher across multi-crop views.

2022 · ICLR

iBOT

EMA teacher 同时充当在线视觉 tokenizer，以图像级 DINO 蒸馏和被遮 patch token 蒸馏联合训练。Uses the EMA teacher simultaneously as an online visual tokenizer to jointly distill masked patch tokens alongside global [CLS] self-distillation.

2024 · TMLR

DINOv2

以 LVD-142M 数据策展配合 DINO+iBOT+KoLeo 复合自监督，并通过跨尺寸蒸馏形成模型家族。Combines automated deduplication/retrieval curation (LVD-142M) with a composite DINO + iBOT + KoLeo objective and multi-resolution distillation.

2022 · ICLR

BEiT

BEiT 的辨识点是预测外部 tokenizer 产生的离散视觉码，而非 MAE 式像素重建或普通对比学习。Pretrains Vision Transformers via BERT-style Masked Image Modeling by predicting discrete visual tokens generated by an external dVAE tokenizer.

2020 · NeurIPS

BYOL

没有负样本队列或聚类码本，核心稳定器是 stop-gradient、EMA 教师和仅在线侧存在的 predictor。Negative-free self-supervised representation learning stabilized by an asymmetric online predictor MLP, stop-gradient, and an EMA target encoder.

2020 · NeurIPS

SwAV

以在线平衡原型分配作为跨视图预测目标，区别于 BYOL 的 EMA 表示回归和 SimCLR 的实例负样本。Replaces pairwise instance comparisons with online Sinkhorn-Knopp balanced prototype cluster assignment and swapped cross-view prediction.
