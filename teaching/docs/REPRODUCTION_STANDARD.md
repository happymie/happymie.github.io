# 复现标准 / Reproduction standard

本项目把可检验的事实写在状态标签中。条目存在、源码下载成功、梯度有限、结构与原文一致、完成原训练、达到论文指标，是不同的验收条件。

| 标签 | 已实现范围 | 不能由此推出 |
| --- | --- | --- |
| `upstream` | 执行指定上游实现或固定版本库；列出构造参数与补丁 | 训练方案、数据、权重或性能与原论文相同 |
| `paper_port` | 独立实现列出的原论文结构/方程，明确缩小配置和省略项 | 未列出的完整流程、全部推断算法、原基准性能 |
| `mechanism_demo` | 只执行列出的部分机制，保留名称用于定位所教方法 | 完整原模型的忠实复现 |
| `source_route` | 来源核查、教学数据库、原版阅读/获取路径 | 已有本地模型实现或 CPU 运行证据 |

`verification.status=completed` 只说明记录中的配置完成指定的训练步数和诊断，损失/梯度有限。它与上面四类来源/实现范围正交，不能覆盖或提升它们。每次记录有代码、数据、依赖版本与测量方法；相同配置也不保证不同硬件完全同速或逐位一致。

## 从本课程走向论文复现

1. 明确目标论文版本和实际代码版本。作者仓库默认分支可能已变成后续模型；来源档案里的 commit 不自动等于执行版本或论文历史版本。
2. 对照网络拓扑、模块公式、激活/归一化、输入归一化、分辨率、tokenizer、位置编码、目标函数与停止梯度路径；记录本课程每项差异。
3. 获得原数据/权重的合法访问，遵循论文划分单位、预处理、患者/机构独立性与评价定义。本项目合成数据不替代这一步。
4. 匹配优化器、调度器、批次、训练长度、随机种子、预训练/微调阶段、提示协议及推断算法。需要的计算资源可能超过笔记本。
5. 在独立测试集上重跑规定指标，给出多种子不确定性、与公开结果的差异、环境版本和完整日志。没有这些证据，不使用“复现论文结果”标签。

## 正确性测试的优先级

测试应能发现一个有科学意义的错误：因果序列看到了未来；教师/EMA 接收到不该有的梯度；图置换改变结果；前向算子与伴随不匹配；盲点目标进入输入；Flow 逆变换不一致；mask 匹配依赖排列；预算漏记最后一步；来源文件哈希不符。仅断言输出 shape 或给任意网络跑两步不够。

逆问题需区分训练先验与后验采样，场优化需区分同场景拟合与新场景泛化，提示分割需说明提示是否由真值生成，基础模型需区分随机初始化架构与大规模预训练后的能力。各模块文档记录这些具体边界。

## 未开源和受限模型

能访问论文不等于能访问完整实现细节。论文移植必须列出未说明的设置与推断，不把推断写成原作者事实。公开可见代码也不自动取得复制权限；保留许可证证据。没有可确认授权或完整实现的条目保留 `source_route`，通过作者路径获取允许使用的材料，不绕过门控，不用后续/近似模型替名。
