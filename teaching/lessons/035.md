# 035 · ConVIRT

[教学网站](https://happymie.github.io/teaching/#model=35) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_035_convirt)

**实现状态：原版学习路径，尚无 CPU 适配器 / Source route**

将自然生成的医学图像–报告对输入全局双塔，通过双向跨模态对比预训练医学视觉 encoder。

Pretrains medical visual encoders directly from naturally occurring paired radiology images and free-text reports via bidirectional contrastive loss.

## 1. 输入、输出与学习目标

- 原模型输入：医学图像与配套自由文本报告 / Paired medical image (e.g., chest X-ray) and corresponding clinical radiology report sentence
- 原模型输出：对齐的图像与报告全局表征 / Contrastively aligned visual encoder representation for downstream low-label classification
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
