# 097 · Florence-2

[教学网站](https://happymie.github.io/teaching/#model=97) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_097_florence_2)

**实现状态：原版学习路径，尚无 CPU 适配器 / Source route**

核心不是增加多个 head，而是用任务提示和位置 token 将 caption、检测、grounding、分割全部改写为 seq2seq。

Reformulates captioning, object detection, phrase grounding, and segmentation into a single prompt-driven sequence-to-sequence generation task with quantized coordinate tokens.

## 1. 输入、输出与学习目标

- 原模型输入：图像与任务提示，例如 caption、detect、ground 或 segment / 2D image + task-specific text prompt (e.g., <OD>, <CAPTION>, <REFERRING_EXPRESSION_SEGMENTATION>)
- 原模型输出：文本、类别与量化位置 token 序列，后处理为描述、框或多边形 / Unified token sequence decoding text descriptions, class labels, and quantized 0–999 bounding-box or polygon coordinates
