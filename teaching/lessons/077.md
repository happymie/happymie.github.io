# 077 · LSTM

[教学网站](https://happymie.github.io/teaching/#model=77) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_077_lstm)

**实现状态：复用上游实现 / Upstream adapter**

带门控的加性 cell memory 与 recurrent hidden state 分离，使长期信息可选择性保留和读出。

Separates an additive linear cell memory state c_t (governed by forget and input gates) from the non-linear recurrent hidden state h_t to preserve long-term temporal gradients.
