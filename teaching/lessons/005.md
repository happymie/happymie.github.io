## 3. 本地实现与 CPU 配置

FCN-8s: VGG pool3/pool4 score fusion plus learned 2x/2x/8x transposed upsampling.

```json
{
  "batch_size": 2,
  "width": 8,
  "fc_width": 64
}
```

配置直接来自实际注册表。宽度、深度、头数或网格尺寸的改变必须满足结构约束；不要把缩小配置的结果写成原模型结果。

**已知差异 / Limitations**

- Random initialization and synthetic data; no original benchmark result or pretrained capability is reproduced.
- Reduced VGG channels/FC widths; same-padding replaces the original padding/cropping boundary convention.
