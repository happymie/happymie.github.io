## 3. 本地实现与 CPU 配置

Encoder-decoder multihead attention, sinusoidal positions, causal target mask and teacher-forced token loss.

```json
{
  "batch_size": 2,
  "d_model": 32,
  "depth": 2,
  "num_heads": 4,
  "vocab_size": 32
}
```

配置直接来自实际注册表。宽度、深度、头数或网格尺寸的改变必须满足结构约束；不要把缩小配置的结果写成原模型结果。

**已知差异 / Limitations**

- Random initialization and synthetic data; no original benchmark result or pretrained capability is reproduced.
- Small vocabulary and token reversal exercise instead of machine translation; no WMT training recipe.
