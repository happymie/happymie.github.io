# 125 · TransMorph

[教学网站](https://happymie.github.io/teaching/#model=125) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_125_transmorph)

**实现状态：复用上游实现 / Upstream adapter**

TransMorph 用层级 Swin encoder 取代纯 CNN 配准编码器，同时保留 U-Net 式 decoder 和可微 warping。

Replaces the convolutional encoder in VoxelMorph with a 3D hierarchical Swin Transformer encoder while retaining a convolutional U-Net decoder and Spatial Transformer warping.

## 1. 输入、输出与学习目标

- 原模型输入：moving 图像 Im 与 fixed 图像 If / Concatenated 3D moving and fixed volumes (I_m, I_f)
- 原模型输出：稠密位移场 φ、warped moving 图像及可选不确定性估计 / Dense 3D displacement field φ, warped moving image I_m ∘ φ, and optional Bayesian uncertainty
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。

## 3. 本地实现与 CPU 配置

Original four-level 3D Swin hierarchy, convolutional decoder, transformer/convolution skips and voxel-unit SpatialTransformer, trained with original MSE plus Grad3d loss.

```json
{
  "width": 8,
  "size": 32
}
```

配置直接来自实际注册表。宽度、深度、头数或网格尺寸的改变必须满足结构约束；不要把缩小配置的结果写成原模型结果。

**已知差异 / Limitations**

- 32-cubed resampled synthetic volumes; embedding width8, two blocks per level, 2-cubed windows and no stochastic depth; both directions accumulated into one optimizer step. Raw flow components are D/H/W voxel displacements; normalized_xyz_flow converts them explicitly.
- Synthetic teaching data only; no clinical validity or published benchmark is claimed.
