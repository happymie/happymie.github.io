# 021 · Vision Transformer (ViT)

[教学网站](https://happymie.github.io/teaching/#model=21) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_021_vision_transformer__vit)

**实现状态：复用上游实现 / Upstream adapter**

非重叠 patch 线性 token 化、CLS 汇聚与全局 Transformer encoder，完全移除卷积主干。

Splits images into non-overlapping patches, linearly projects them into tokens with positional embeddings, and processes them via a pure global Transformer encoder.

## 1. 输入、输出与学习目标

- 原模型输入：固定分辨率二维图像 / Fixed-resolution 2D image (or 3D sub-volume patches)
- 原模型输出：CLS 全局表征或类别概率 / Global [CLS] representation, patch token grid, or classification logits
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。
