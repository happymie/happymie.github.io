# 034 · SAM 2

[教学网站](https://happymie.github.io/teaching/#model=34) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_034_sam_2)

**实现状态：原版学习路径，尚无 CPU 适配器 / Source route**

在 SAM 提示式 decoder 外加入 memory attention、mask-conditioned memory encoder 和 object pointer，构成可交互的流式时序闭环。

Extends promptable SAM with a streaming memory bank, memory cross-attention, mask-conditioned memory encoder, and occlusion score head across sequences.

## 1. 输入、输出与学习目标

- 原模型输入：图像或视频帧、当前帧提示及历史对象记忆 / Video stream or 3D slice stack + spatial prompts (points/box/mask) on one or more reference frames
- 原模型输出：当前帧对象 mask，并更新供后续帧读取的记忆 / Temporally/slice-propagated segmentation masks with updated object memory state
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。
