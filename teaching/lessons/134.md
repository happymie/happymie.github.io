# 134 · Voxel2Mesh

[教学网站](https://happymie.github.io/teaching/#model=134) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_134_voxel2mesh)

**实现状态：原版学习路径，尚无 CPU 适配器 / Source route**

Voxel2Mesh 不先分割再 marching cubes，而由 3D 体素特征逐级驱动球形模板的 GCN 形变和细分。

Deforms a sphere template mesh progressively into a target 3D anatomical surface via Graph Convolutions conditioned on 3D CNN voxel features sampled at mesh vertices.

## 1. 输入、输出与学习目标

- 原模型输入：3D 医学体积与初始球形模板 mesh / 3D medical imaging volume (CT/MRI/EM) + initial genus-0 spherical template mesh
- 原模型输出：器官表面的顶点、三角面与可选体素分割 / Explicit 3D anatomical triangle mesh (vertices V, faces F) and auxiliary voxel segmentation
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。
