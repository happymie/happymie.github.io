# 080 · LaBraM

[教学网站](https://happymie.github.io/teaching/#model=80) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_080_labram)

**实现状态：复用上游实现 / Upstream adapter**

以 VQ neural tokenizer 提供离散 EEG patch 目标，再用跨通道/时间 Transformer 做 masked code prediction。

Trains a vector-quantized (VQ) neural spectrum tokenizer to predict Fourier amplitude/phase spectra of EEG patches, then pretrains a cross-channel Transformer via masked code prediction.

## 1. 输入、输出与学习目标

- 原模型输入：多通道连续 EEG 片段及通道身份 / Multi-channel continuous EEG recordings with arbitrary montage channel counts and recording lengths
- 原模型输出：通用 EEG 表征与下游分类/检测输出 / Universal EEG representation transferable across seizure detection, sleep staging, emotion, and motor BCI
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。

## 3. 本地实现与 CPU 配置

The authors' TemporalConv and NeuralTransformer operate on channel-by-time patches with separate learned electrode and time embeddings and Q/K normalization.

```json
{
  "batch_size": 2,
  "patch_size": 200,
  "patches": 2,
  "temporal_channels": 4,
  "depth": 2,
  "num_heads": 4
}
```

配置直接来自实际注册表。宽度、深度、头数或网格尺寸的改变必须满足结构约束；不要把缩小配置的结果写成原模型结果。

**已知差异 / Limitations**

- Architecture-only exercise: VQ neural tokenizer, masked code prediction, full pretraining corpus and pretrained LaBraM capability are not reproduced.
- Synthetic waveforms are interpolated to two 200-sample patches per channel. This is a shape adapter, not an assertion of EEG sampling rate or a source of extra information.
- Synthetic channel IDs 1..C have no anatomical electrode identity. Real EEG requires explicit montage, channel-order, unit and sampling checks.
- Width 100 and depth two replace the original base preset; all weights are random.
