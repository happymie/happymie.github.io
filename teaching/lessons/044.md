# 044 · GAN

**实现状态：独立论文结构或方程实现 / Paper port**

生成器与判别器通过同一 value function 对抗优化，以数据驱动判别器替代固定重建损失。

Generator and discriminator networks engage in a two-player minimax game, replacing hand-crafted pixel reconstruction losses with a learned adversarial critic.
