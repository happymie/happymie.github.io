# 126 · IDIR

[教学网站](https://happymie.github.io/teaching/#model=126) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_126_idir)

**实现状态：独立论文结构或方程实现 / Paper port**

IDIR 将位移场本身作为坐标神经场，并在测试图像对上直接优化，而不是由训练好的网络一次预测 flow。

Parameterizes the continuous 3D deformation field φ(x) = x + u_θ(x) for a single image pair directly as a coordinate-based Implicit Neural Representation (SIREN MLP) optimized at test time.

## 1. 输入、输出与学习目标

- 原模型输入：一对 fixed/moving 图像及在图像域采样的连续坐标 x / Continuous 3D spatial coordinates x ∈ [-1,1]³ sampled over a fixed/moving volume pair (I_f, I_m)
- 原模型输出：可在任意坐标查询的连续位移场 uθ(x) 和 warped moving 图像 / Resolution-independent continuous deformation field φ_θ(x) with exact autograd spatial derivatives
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。

## 3. 本地实现与 CPU 配置

A SIREN coordinate network fits one image pair's displacement at test time with autograd spatial derivatives.

**已知差异 / Limitations**

- Only the first synthetic pair is fitted; smoothness regularization rather than every original Jacobian/bending variant; normalized coordinates.
- Synthetic teaching data only; no clinical validity or published benchmark is claimed.
