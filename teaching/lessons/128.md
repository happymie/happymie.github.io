# 128 · pixelNeRF

[教学网站](https://happymie.github.io/teaching/#model=128) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_128_pixelnerf)

**实现状态：部分机制演示 / Mechanism demo**

pixelNeRF 将每个 3D 点与其投影像素的 CNN 特征绑定，使 NeRF 从单场景优化器变为跨场景条件模型。

Conditions a coordinate NeRF MLP on pixel-aligned 2D CNN feature vectors projected from 1 or a few input views, turning NeRF from a per-scene optimizer into a feed-forward cross-scene prior.

## 1. 输入、输出与学习目标

- 原模型输入：一张或少量带相机位姿的参考图像，以及目标相机射线 / 1 to K calibrated input images + query 3D point x projected into each input view's camera coordinates
- 原模型输出：目标视角 RGB 图像和隐式密度/辐射场 / Feed-forward novel-view rendering and 3D volumetric density field from sparse views
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。

## 3. 本地实现与 CPU 配置

Project world points into a known reference camera, sample aligned CNN features and condition a radiance field for a new view.

```json
{

  "ray_samples": 16
}
```

配置直接来自实际注册表。宽度、深度、头数或网格尺寸的改变必须满足结构约束；不要把缩小配置的结果写成原模型结果。

**已知差异 / Limitations**

- Single reference view, small encoder/MLP and synthetic scenes; no original ResNet encoder or multiview feature aggregation.
- Synthetic teaching data only; no clinical validity or published benchmark is claimed.
