# 064 · Consistency Models

[教学网站](https://happymie.github.io/teaching/#model=64) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_064_consistency_models)

**实现状态：独立论文结构或方程实现 / Paper port**

学习沿 PF-ODE 轨迹不变的 endpoint map，使任意噪声尺度可直接一步映射到 clean sample。

Learns a self-consistent function f_θ(x_t, t) = x_ε that maps any point along a Probability-Flow ODE trajectory directly to its clean origin in a single step.

## 1. 输入、输出与学习目标

- 原模型输入：噪声状态 x_t；蒸馏模式下还需预训练 diffusion score teacher / Noisy state x_t along a PF-ODE trajectory (distilled from a pretrained score model or trained standalone)
- 原模型输出：一次或少数几次函数调用得到的 clean sample / One-step or few-step clean sample estimate x̂_0
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。
