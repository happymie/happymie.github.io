# 076 · GAT

[教学网站](https://happymie.github.io/teaching/#model=76) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_076_gat)

**实现状态：复用上游实现 / Upstream adapter**

对预定义邻域内的边计算 masked multi-head attention，再以数据依赖权重聚合邻居特征。

Replaces fixed degree-normalized edge weights with content-dependent multi-head masked self-attention coefficients α_{ij} computed over 1-hop graph neighborhoods.
