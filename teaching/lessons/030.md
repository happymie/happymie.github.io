# 030 · CLIP

[教学网站](https://happymie.github.io/teaching/#model=30) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_030_clip)

**实现状态：复用上游实现 / Upstream adapter**

完全分离的图像/文本双塔，通过批内 N×N 对称对比目标对齐，并用文本 prompt 充当开放词表分类器。

Aligns separate image and text encoders in a shared embedding space via symmetric in-batch N×N contrastive loss, turning text prompts into zero-shot classifiers.

## 1. 输入、输出与学习目标

- 原模型输入：批量图像与自然语言文本配对 / Mini-batch of N paired (image, natural-language caption) samples
- 原模型输出：共享嵌入空间中的图像/文本向量与零样本类别分数 / L2-normalized shared-space image/text embeddings and cosine zero-shot classification logits
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。

## 3. 本地实现与 CPU 配置

Original OpenAI ViT image encoder, causal text Transformer, EOT pooling, learned logit scale and symmetric image–text contrastive loss.

```json

  "text_width": 64,
  "text_heads": 4,
  "text_layers": 2,

```

配置直接来自实际注册表。宽度、深度、头数或网格尺寸的改变必须满足结构约束；不要把缩小配置的结果写成原模型结果。

**已知差异 / Limitations**

- Unmodified MIT author architecture with smaller dimensions and random initialization; no pretrained weights or foundation-pretraining claim.
- Synthetic grayscale images are repeated into RGB. A 32-token teaching vocabulary replaces byte-pair tokenization; EOS=2 is explicitly remapped to the largest token ID required by original CLIP pooling.
- Paired diagonal contrastive targets are retained. Repeated short synthetic descriptions can be false negatives; tiny batches do not establish semantic retrieval or zero-shot quality.
