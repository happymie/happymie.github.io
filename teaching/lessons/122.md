# 122 · PFGM++

[教学网站](https://happymie.github.io/teaching/#model=122) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_122_pfgm)

**实现状态：独立论文结构或方程实现 / Paper port**

PFGM++ 用可调增广维度 D 的 Poisson 电场统一 PFGM 与 diffusion，而不是固定高斯前向噪声过程。

Embeds N-dimensional data on the z=0 hyperplane of an N+D augmented space and learns the high-dimensional Poisson electric field lines, unifying PFGM (D=1) and Diffusion (D→∞).

## 1. 输入、输出与学习目标

- 原模型输入：训练数据 x∈R^N；采样时为 N+D 维简单先验状态 / Training data x ∈ R^N embedded in R^{N+D}; hemispherical prior samples at large radius r_max during generation
- 原模型输出：沿学习电场 ODE 流回数据超平面的生成样本 / Samples generated by integrating the learned augmented electric field ODE back to the z=0 hyperplane
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。

## 3. 本地实现与 CPU 配置

A Beta(N/2,D/2) radial perturbation law and EDM-preconditioned denoising learn the finite-D augmented Poisson field.

```json
{
  "size": 16,
  "width": 8,
  "augmented_dim": 64
}
```

配置直接来自实际注册表。宽度、深度、头数或网格尺寸的改变必须满足结构约束；不要把缩小配置的结果写成原模型结果。

**已知差异 / Limitations**

- Finite augmented dimension D=64 and compact network; original PFGM corresponds to D=1, not a D-to-zero limit; no full ODE sampler.
- Synthetic teaching data only; no clinical validity or published benchmark is claimed.
