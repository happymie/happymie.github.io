# 052 · DnCNN

[教学网站](https://happymie.github.io/teaching/#model=52) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_052_dncnn)

**实现状态：复用上游实现 / Upstream adapter**

深 CNN 回归噪声残差，再与输入显式相减，而非直接回归 clean image。

Trains a deep plain CNN with BatchNorm and ReLU to regress the additive noise residual R_θ(y) ≈ n rather than the clean image, recovering x̂ = y − R_θ(y).

## 1. 输入、输出与学习目标

- 原模型输入：含噪图像 y=x+n / Noisy observation y = x + n
- 原模型输出：去噪图像 x_hat=y-R_theta(y) / Denoised image estimate x̂ = y − R_θ(y)
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
