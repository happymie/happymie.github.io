# 053 · Noise2Noise

[教学网站](https://happymie.github.io/teaching/#model=53) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_053_noise2noise)

**实现状态：独立论文结构或方程实现 / Paper port**

使用同一信号的两次独立无偏噪声实现进行 noisy-to-noisy 监督，训练阶段不需要干净靶图。

Trains a denoising network using pairs of independent noisy realizations (y_1, y_2) of the same underlying anatomy without ever observing clean ground truth.

## 1. 输入、输出与学习目标

- 原模型输入：同一潜在图像 x 的两次独立含噪观测 y1、y2 / Two independent noisy observations (y_1, y_2) of the exact same underlying clean signal x
- 原模型输出：以单次含噪观测为输入的条件均值估计 x_hat / Clean conditional expectation estimate x̂ = f_θ(y_1)
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。
