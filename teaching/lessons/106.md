# 106 · CHIEF

[教学网站](https://happymie.github.io/teaching/#model=106) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_106_chief)

**实现状态：原版学习路径，尚无 CPU 适配器 / Source route**

CHIEF 明确串联 CTransPath tile 自监督和带解剖条件的 WSI attention 弱监督，而非只发布局部 patch encoder。

Couples self-supervised tile encoding (CTransPath) with anatomical-site-conditioned whole-slide attention aggregation trained across 60,530 WSIs.

## 1. 输入、输出与学习目标

- 原模型输入：H&E WSI、tile 特征及训练时的癌症/解剖部位弱标签 / H&E whole-slide image tiles + anatomical primary site text/categorical embedding
- 原模型输出：通用 tile embedding、WSI embedding 和诊断/预后任务输出 / Slide-level diagnostic representation for cancer detection, tumor origin, genomic mutation, and survival prediction
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。
