TITAN 的特异性是三阶段 whole-slide 预训练：特征网格 iBOT、ROI caption CoCa、WSI report CoCa。

Three-stage multimodal whole-slide foundation model pretrained via iBOT on 2D tile feature grids, CoCa on synthetic ROI captions, and CoCa on whole-slide pathology reports.

## 1. 输入、输出与学习目标

- 原模型输入：预提取病理 patch 网格、ROI 合成描述和 WSI 病理报告 / Pre-extracted 2D spatial grid of WSI patch embeddings (CONCH v1.5) + ROI descriptions / clinical pathology reports
- 原模型输出：通用 whole-slide embedding、跨模态检索分数与病理文本生成 / General-purpose whole-slide embedding, zero-shot slide classification, cross-modal report retrieval, and slide report generation
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
