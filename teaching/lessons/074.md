# 074 · 3D Gaussian Splatting

[教学网站](https://happymie.github.io/teaching/#model=74) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_074_3d_gaussian_splatting)

**实现状态：部分机制演示 / Mechanism demo**

显式优化各向异性 3D Gaussians，并通过屏幕空间 splatting 与自适应增密实现实时 radiance rendering。

Represents 3D scenes explicitly as millions of anisotropic 3D Gaussians (position, covariance, opacity, spherical harmonics) rendered in real time via differentiable tile-based rasterization.

## 1. 输入、输出与学习目标

- 原模型输入：带标定多视角 RGB 图像与 SfM/点云初始化 / Calibrated multi-view images and initial sparse point cloud
- 原模型输出：可实时新视角渲染的显式 3D Gaussian 集合 / Explicit set of anisotropic 3D Gaussians supporting >100 FPS real-time novel-view synthesis

## 3. 本地实现与 CPU 配置

Perspective Jacobians project anisotropic 3D Gaussian covariances; depth-sorted opacities alpha-compose colors.

```json
{
  "gaussians": 16,
  "size": 16
}
```

配置直接来自实际注册表。宽度、深度、头数或网格尺寸的改变必须满足结构约束；不要把缩小配置的结果写成原模型结果。

**已知差异 / Limitations**

- Dense CPU rasterizer with sixteen Gaussians; no CUDA tile renderer, densification, pruning or nonconstant spherical harmonics.
- Synthetic teaching data only; no clinical validity or published benchmark is claimed.
