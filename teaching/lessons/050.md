# 050 · MoDL

[教学网站](https://happymie.github.io/teaching/#model=50) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_050_modl)

**实现状态：独立论文结构或方程实现 / Paper port**

共享 CNN prior 与可微共轭梯度 data-consistency 子问题交替展开。

Alternates a weight-shared multi-layer CNN denoiser prior D_θ with a differentiable numerical Conjugate Gradient (CG) solver enforcing exact data consistency (A*A + λI)^{-1}.

## 1. 输入、输出与学习目标

- 原模型输入：测量 y、已知前向算子 A 与伴随 A* / Undersampled multi-coil k-space measurements b, forward operator A (incorporating coil maps + FFT + mask), and adjoint A*
- 原模型输出：K 次共享权重迭代后的重建 x_hat / Reconstructed MRI image x_K after K weight-shared alternating minimization stages
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。

## 3. 本地实现与 CPU 配置

One shared residual CNN alternates with differentiable CG solves of (A* A + lambda I)x=A*y+lambda D(x).

```json
{
  "size": 16,
  "width": 8,
  "stages": 3

```

配置直接来自实际注册表。宽度、深度、头数或网格尺寸的改变必须满足结构约束；不要把缩小配置的结果写成原模型结果。

**已知差异 / Limitations**

- Eight CG iterations approximate each solve; three unrolls and synthetic Cartesian two-coil data.
- Synthetic teaching data only; no clinical validity or published benchmark is claimed.
