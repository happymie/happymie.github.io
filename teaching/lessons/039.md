# 039 · UNI

[教学网站](https://happymie.github.io/teaching/#model=39) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_039_uni)

**实现状态：原版学习路径，尚无 CPU 适配器 / Source route**

在超过一亿病理图块上以 DINOv2 式 teacher–student 训练 ViT-L/16，向多类病理任务提供统一冻结 tile encoder。

ViT-L/16 tile encoder pretrained via DINOv2 self-distillation and iBOT masked patch modeling on over 100 million H&E histopathology patches (Mass-100K).

## 1. 输入、输出与学习目标

- 原模型输入：全视野病理切片切出的无标签组织图块 / 256×256 H&E histopathology tissue tiles extracted from whole-slide images (WSIs)
- 原模型输出：可冻结迁移的病理图块表征及其下游切片级聚合 / Frozen transferable tile embeddings for ROI tasks or MIL whole-slide aggregation
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。

## 5. 运行或获取原版

先按 [README](../README.md) 安装，在 `teaching/` 目录执行。以下是 Linux/Apple Silicon 路径；Windows 将 `.venv/bin/python` 换为 `.venv\Scripts\python.exe`。

```bash
.venv/bin/python -m biomed_lab info 039
.venv/bin/python -m biomed_lab data 039 --inspect
.venv/bin/python -m biomed_lab fetch-upstream 039
```

运行日志在新的 `runs/` 子目录中；验证状态、预算和失败均需保留。获取原版命令只下载固定源码，不安装、执行原脚本或下载权重。部分原版流程所需数据、访问与计算资源仍由作者文档规定。
