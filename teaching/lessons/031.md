# 031 · BLIP-2

[教学网站](https://happymie.github.io/teaching/#model=31) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_031_blip_2)

**实现状态：复用上游实现 / Upstream adapter**

Q-Former 的 learnable queries 作为冻结图像 encoder 与冻结 LLM 之间唯一可训练的视觉信息瓶颈。

Bridges a frozen pretrained image encoder to a frozen LLM using a lightweight Querying Transformer (Q-Former) with learnable query tokens as an information bottleneck.

## 1. 输入、输出与学习目标

- 原模型输入：图像与文本配对，生成阶段输入图像和文本 prompt / Image + text caption (Stage 1) or image + natural-language instruction prompt (Stage 2)
- 原模型输出：图像条件文本或视觉语言表征 / Fixed-length visual query embeddings and autoregressive image-conditioned text generation
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。

## 3. 本地实现与 CPU 配置

Pinned Transformers BLIP-2 ViT, learned query tokens, Q-Former cross-attention, projection and frozen OPT causal language model; train only the stage-two visual-language bridge.

```json
{
  "image_size": 32,
  "patch_size": 8,
  "width": 32,
  "depth": 2,
  "heads": 4,
  "query_tokens": 4,
  "context_length": 16,
  "vocab_size": 32
}
```

配置直接来自实际注册表。宽度、深度、头数或网格尺寸的改变必须满足结构约束；不要把缩小配置的结果写成原模型结果。

**已知差异 / Limitations**

- Canonical Apache-2.0 library implementation, not copied Salesforce LAVIS training code. All modules start randomly initialized at reduced dimensions; frozen random ViT/OPT have no pretrained visual or language knowledge.
- Only the stage-two bridge architecture and causal caption loss are exercised. Stage-one image-text contrastive, image-text matching and image-grounded generation pretraining, instruction tuning and real caption data are absent.
- Synthetic vocabulary replaces the original tokenizer. Vision initialization and learned query tokens use normal std=0.02 to avoid the library checkpoint-oriented near-zero/zero defaults. No image-captioning or question-answering capability is claimed.
