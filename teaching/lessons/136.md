# 136 · GRU

[教学网站](https://happymie.github.io/teaching/#model=136) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_136_gru)

**实现状态：复用上游实现 / Upstream adapter**

GRU 用 reset/update 两门和单一隐藏状态完成记忆更新，结构比 LSTM 更简洁。

Simplifies gated recurrence by merging cell and hidden states into a single vector h_t interpolated via an update gate z_t and a reset gate r_t.

## 1. 输入、输出与学习目标

- 原模型输入：时间序列 xt 与上一隐藏状态 ht−1 / Sequential physiological or clinical feature vector x_t and previous hidden state h_{t-1}
- 原模型输出：当前隐藏状态 ht、全序列表示或逐时刻预测 / Updated hidden state h_t or sequence prediction
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。

## 3. 本地实现与 CPU 配置

Update and reset gates control recurrent state without a separate cell state.

```json

```

配置直接来自实际注册表。宽度、深度、头数或网格尺寸的改变必须满足结构约束；不要把缩小配置的结果写成原模型结果。

**已知差异 / Limitations**

- Direct PyTorch GRU applies reset after the recurrent linear map; the Cho et al. original formulation places it before. Not claimed bitwise equivalent to that original equation.
