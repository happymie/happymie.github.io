# 103 · MAIRA-2

[教学网站](https://happymie.github.io/teaching/#model=103) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_103_maira_2)

**实现状态：原版学习路径，尚无 CPU 适配器 / Source route**

相较 MAIRA-1，MAIRA-2 增加多视图/既往/报告上下文，并把报告句子与生成式 bounding-box token 绑定。

Extends MAIRA-1 with multi-view (AP/PA + lateral), prior study/report longitudinal context, and interleaved quantized bounding-box tokens for grounded reporting.

## 1. 输入、输出与学习目标

- 原模型输入：当前正位/侧位胸片、既往正位胸片与报告、indication、technique、comparison 和任务提示 / Current frontal & lateral CXR, prior CXR, prior report, indication, technique, comparison + task prompt
- 原模型输出：普通 Findings、逐句关联边界框的 grounded Findings，或短语定位框 / Ungrounded Findings, spatially grounded Findings (linking each clinical sentence to bounding boxes), or phrase grounding
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。
