# 117 · AUTOMAP

[教学网站](https://happymie.github.io/teaching/#model=117) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_117_automap)

**实现状态：部分机制演示 / Mechanism demo**

AUTOMAP 的标志是大规模全连接层直接承担 domain transform，而非先做 FBP/IFFT 再用 CNN 后处理。

Learns the sensor-to-image domain transform directly via large fully connected layers mapping flattened raw measurements to an image grid followed by sparse convolutional refinement.

## 1. 输入、输出与学习目标

- 原模型输入：MRI k-space、CT 投影等序列化测量向量 / Flattened raw sensor measurement vector (e.g., k-space samples or Radon projections)
- 原模型输出：重建图像 / Reconstructed spatial-domain image
