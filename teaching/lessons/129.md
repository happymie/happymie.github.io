# 129 · Instant-NGP

[教学网站](https://happymie.github.io/teaching/#model=129) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_129_instant_ngp)

**实现状态：部分机制演示 / Mechanism demo**

Instant-NGP 的速度来自可学习多分辨率 hash-grid encoding 和空空间跳跃，而不是更深的 NeRF MLP。

Replaces fixed sinusoidal positional encodings with a multi-resolution hierarchy of learnable hash tables paired with a tiny fused-CUDA MLP, accelerating neural fields by 100×–1000×.

## 1. 输入、输出与学习目标

- 原模型输入：3D 坐标、观察方向及训练相机射线 / Continuous 3D coordinate x ∈ R³ mapped across L resolution grids via spatial hashing
- 原模型输出：快速优化的 density/color 场与实时新视角渲染 / Concatenated L×F interpolated feature vector decoded in microseconds into density/attenuation/SDF
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。

## 3. 本地实现与 CPU 配置

Learnable multiresolution hash tables interpolate features at eight cell corners before a small radiance decoder.

- CPU PyTorch implementation; no fused CUDA kernels, occupancy skipping or claimed real-time performance.
- Synthetic teaching data only; no clinical validity or published benchmark is claimed.
