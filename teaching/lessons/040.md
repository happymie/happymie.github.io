**实现状态：原版学习路径，尚无 CPU 适配器 / Source route**

在病理领域把 CLIP 式全局对比与 CoCa 式图像条件 caption decoder 联合训练，同时服务判别与生成。

CoCa-style computational pathology vision–language foundation model jointly trained with contrastive image–text alignment and generative caption decoding on 1.17M pairs.

## 1. 输入、输出与学习目标

- 原模型输入：组织病理图像与人工生成的病理文本描述 / Histopathology image tile/ROI + paired pathology text description or prompt
- 原模型输出：病理图文共享表征及图像条件文本生成 / Shared multimodal retrieval/zero-shot embeddings + autoregressive pathology caption/text generation
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。
