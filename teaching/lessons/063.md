# 063 · Rectified Flow

[教学网站](https://happymie.github.io/teaching/#model=63) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_063_rectified_flow)

**实现状态：独立论文结构或方程实现 / Paper port**

以直线端点路径训练 velocity，并通过 reflow 重新耦合端点以进一步拉直 ODE 轨迹。

Learns an ODE velocity field along straight linear interpolations x_t = (1−t)x_0 + t x_1 and iteratively straightens trajectories via reflow recoupling.

## 1. 输入、输出与学习目标

- 原模型输入：源噪声 z0 与目标数据 x1 的 coupling / Coupled pairs (x_0, x_1) from source distribution π_0 and target distribution π_1
- 原模型输出：沿近直线 ODE 少步运输得到的样本 x_hat / Nearly straight-line ODE transport trajectories enabling high-fidelity 1-to-few-step Euler generation
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。
