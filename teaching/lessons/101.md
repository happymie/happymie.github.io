# 101 · RadFM

[教学网站](https://happymie.github.io/teaching/#model=101) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_101_radfm)

**实现状态：原版学习路径，尚无 CPU 适配器 / Source route**

RadFM 的模型特异性在于统一 2D/3D 视觉 encoder 与 Perceiver 扫描聚合，再接生成式 LLM。

Unifies 2D radiographs and 3D volumetric scans (CT/MRI) via a 2D/3D ViT + Perceiver 3D aggregator feeding into a generative radiology LLM.

## 1. 输入、输出与学习目标

- 原模型输入：一张或一组 2D 图像、3D CT/MRI 体积及文本指令 / Single/multiple 2D radiographs or 3D CT/MRI volumes + natural-language clinical instruction
- 原模型输出：放射学自由文本回答、报告或识别结果 / Free-text radiology report, VQA answer, abnormality diagnosis, or rationale
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。
