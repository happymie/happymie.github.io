# 095 · ALIGN

[教学网站](https://happymie.github.io/teaching/#model=95) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_095_align)

**实现状态：复用上游实现 / Upstream adapter**

ALIGN 的主要贡献不是新交互模块，而是简单 EfficientNet/BERT 双塔在十亿级未精洗图文对上的规模化训练。

Demonstrates that a simple EfficientNet + BERT dual encoder trained on over one billion noisy web image–alt-text pairs learns robust cross-modal representations.

## 1. 输入、输出与学习目标

- 原模型输入：网页图像与未经精细清洗的 alt-text 对 / Web image + minimally filtered raw alt-text description
- 原模型输出：共享空间中的图像和文本 embedding，用于检索与零样本分类 / Shared-space image and text embeddings for cross-modal retrieval and zero-shot classification
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。

## 3. 本地实现与 CPU 配置

Pinned Transformers ALIGN: seven-stage EfficientNet MBConv/SE image tower, BERT text tower, normalized embeddings, learned temperature and symmetric label-smoothed contrastive loss.

```json
{
  "image_size": 32,
  "width_coefficient": 0.25,
  "depth_coefficient": 0.25,
  "text_width": 32,
  "text_depth": 2,
  "text_heads": 4,
  "context_length": 16,
  "vocab_size": 32
}
```

配置直接来自实际注册表。宽度、深度、头数或网格尺寸的改变必须满足结构约束；不要把缩小配置的结果写成原模型结果。

**已知差异 / Limitations**

- Canonical Apache-2.0 library implementation follows the Kakao Brain reproduction; it is not Google's unreleased original training implementation or checkpoint.
- Reduced width/depth with random initialization, 32-token synthetic vocabulary and two paired images replace web-scale noisy image-text training. All seven EfficientNet stage types remain; each has at least one block.
- Vision initializer std=0.1 replaces the library's checkpoint-oriented 0.02, whose deep uncalibrated random tower can underflow during evaluation. Synthetic images use [-1,1] normalization without original data augmentation; no foundation retrieval or zero-shot performance is established.
