# 089 · DeiT

[教学网站](https://happymie.github.io/teaching/#model=89) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_089_deit)

**实现状态：部分机制演示 / Mechanism demo**

增加 distillation token 和专用 head，使 CNN teacher 信号通过 Transformer attention 注入 ViT。

Augments ViT with a learnable distillation token that interacts with patch tokens via self-attention to distill inductive biases from a CNN teacher.

## 1. 输入、输出与学习目标

- 原模型输入：ImageNet/医学 2D 图像与训练时 CNN teacher logits / 2D image (plus CNN teacher hard predictions during training)
- 原模型输出：class token 与 distillation token 融合的分类预测 / Fused class-token and distillation-token classification prediction
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。

## 3. 本地实现与 CPU 配置

timm distilled ViT has separate class/distillation tokens and heads; hard teacher targets supervise the distillation head.

```json
{
  "batch_size": 2,
  "image_size": 32,
  "patch_size": 4,
  "hidden_size": 32,
  "depth": 2,
  "num_heads": 4
}
```

配置直接来自实际注册表。宽度、深度、头数或网格尺寸的改变必须满足结构约束；不要把缩小配置的结果写成原模型结果。

**已知差异 / Limitations**

- Random initialization and synthetic data; no original benchmark result or pretrained capability is reproduced.
- Default teacher is an explicit analytic classifier of synthetic shape fill ratio, not the paper's pretrained RegNetY. Supply teacher_logits for a real teacher.
- CPU dimensions differ from the paper's training preset; see the explicit configuration.
