# 065 · DiT

[教学网站](https://happymie.github.io/teaching/#model=65) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_065_dit)

**实现状态：复用上游实现 / Upstream adapter**

把 noisy latent patch 化，以 adaLN-Zero 条件化的 Transformer blocks 作为 diffusion score/velocity backbone。

Replaces the convolutional U-Net backbone in Latent Diffusion with an isotropic Vision Transformer over latent patches conditioned via Adaptive LayerNorm-Zero (adaLN-Zero).

## 1. 输入、输出与学习目标

- 原模型输入：加噪 latent 图像 z_t、时间 t 与可选类别/条件 c / Noisy latent tensor z_t, diffusion timestep t, and conditioning embedding c
- 原模型输出：epsilon/score 参数与可选方差预测，经逆扩散得到并解码的图像 / Predicted noise ε_θ, diagonal covariance Σ_θ, or velocity v_θ on the latent token grid
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。
