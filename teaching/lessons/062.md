# 062 · Flow Matching

[教学网站](https://happymie.github.io/teaching/#model=62) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_062_flow_matching)

**实现状态：独立论文结构或方程实现 / Paper port**

在已知 probability path 上回归 velocity（而非 score），再直接积分神经 ODE 完成分布运输。

Trains continuous normalizing flows without ODE simulation by directly regressing the marginal vector field u_t(x) along conditional probability paths.

## 1. 输入、输出与学习目标

- 原模型输入：源分布样本 x0（通常高斯噪声）与数据样本 x1 / Source prior sample x_0 ~ p_0 and target data sample x_1 ~ p_1 interpolated along a conditional path x_t
- 原模型输出：沿学习 ODE 从源分布运输得到的生成样本 / Samples generated by integrating the learned velocity field dx/dt = v_θ(x_t, t) from t=0 to t=1
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。

- Small positive sigma_min leaves endpoint smoothing; this is the conditional OT path, not every flow-matching variant.
