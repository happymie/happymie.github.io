# 135 · Vox2Cortex

[教学网站](https://happymie.github.io/teaching/#model=135) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_135_vox2cortex)

**实现状态：原版学习路径，尚无 CPU 适配器 / Source route**

Vox2Cortex 将 3D U-Net 特征在顶点处采样，并以 GCN 同时形变四个互相关联的皮层表面。

Jointly deforms four topologically coupled brain cortical hemisphere templates (left/right white and pial surfaces) in seconds using 3D U-Net voxel features and Residual GCNs.

## 1. 输入、输出与学习目标

- 原模型输入：3D T1-weighted brain MRI 与四个初始皮层模板表面 / 3D T1-weighted brain MRI + 4 initialized template meshes (~168,000 total vertices)
- 原模型输出：左右半球 white 与 pial 四个显式 cortical meshes / 4 high-resolution, topologically genus-zero cortical meshes (LH/RH white matter and pial surfaces)
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。

## 3. 尚未完成的实现

Vox2Cortex requires cortical surface topology, volumetric feature sampling and coupled mesh refinement/losses. These have not been implemented in this CPU lab; original GPL source remains linked.
