# 108 · PRISM2

**实现状态：原版学习路径，尚无 CPU 适配器 / Source route**

PRISM2 明确提供双嵌入：Perceiver 的通用 base embedding，以及 Phi-3 隐状态导出的诊断 embedding。

Pairs a Perceiver slide encoder over Virchow2 tile embeddings with a Phi-3 LLM trained on single-turn clinical dialogues derived from pathology reports, exposing dual embeddings.

## 1. 输入、输出与学习目标

- 原模型输入：一个病例的一张或多张 H&E WSI、文本提示与由报告改写的单轮临床对话 / Multi-slide H&E case tile embeddings (Virchow2) + clinical prompt / diagnostic query
- 原模型输出：2560 维 base embedding、3072 维 diagnostic embedding、报告或问答文本 / 2560-D base slide embedding, 3072-D LLM diagnostic embedding, or autoregressive pathology text response
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。
