# 094 · SwAV

[教学网站](https://happymie.github.io/teaching/#model=94) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_094_swav)

**实现状态：部分机制演示 / Mechanism demo**

以在线平衡原型分配作为跨视图预测目标，区别于 BYOL 的 EMA 表示回归和 SimCLR 的实例负样本。

Replaces pairwise instance comparisons with online Sinkhorn-Knopp balanced prototype cluster assignment and swapped cross-view prediction.

## 1. 输入、输出与学习目标

- 原模型输入：同一图像的两张全局裁剪和若干局部裁剪 / 2 global high-resolution views + M small local crops of the same image
- 原模型输出：可迁移图像表示与在线 prototype 分配 / Transferable visual backbone and online learnable prototype codebook
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。

## 3. 本地实现与 CPU 配置

Entropy-regularized balanced Sinkhorn assignments from one view supervise prototype scores in the other.

```json
{
  "width": 32,
  "prototypes": 8
}
```

配置直接来自实际注册表。宽度、深度、头数或网格尺寸的改变必须满足结构约束；不要把缩小配置的结果写成原模型结果。

**已知差异 / Limitations**

- Small two-view experiment; no multi-crop queue/distributed training. Tiny batches are an objective exercise, not evidence of learned transfer.
