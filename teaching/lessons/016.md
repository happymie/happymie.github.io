# 016 · Mamba

[教学网站](https://happymie.github.io/teaching/#model=16) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_016_mamba)

**实现状态：复用上游实现 / Upstream adapter**

由当前输入生成 Δ、B、C 的 selective SSM，并用硬件感知并行 scan 执行。

Makes SSM discretization step Δ and projections B, C functions of the current input x_k, executed via a hardware-aware parallel associative scan.

**已知差异 / Limitations**

- Random initialization and synthetic data; no original benchmark result or pretrained capability is reproduced.
- Python reference scan is slower than CUDA fused kernels; small sequence classification head added.
