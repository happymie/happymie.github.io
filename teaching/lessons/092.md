# 092 · BEiT

[教学网站](https://happymie.github.io/teaching/#model=92) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_092_beit)

**实现状态：部分机制演示 / Mechanism demo**

BEiT 的辨识点是预测外部 tokenizer 产生的离散视觉码，而非 MAE 式像素重建或普通对比学习。

Pretrains Vision Transformers via BERT-style Masked Image Modeling by predicting discrete visual tokens generated by an external dVAE tokenizer.

## 1. 输入、输出与学习目标

- 原模型输入：原始图像，以及对其 patch 随机遮挡后的 token 序列 / Raw image (for dVAE tokenizer) + block-wise masked patch sequence (for ViT encoder)
- 原模型输出：被遮挡位置的离散视觉 token 分布；微调时复用 Transformer 图像表示 / Categorical distribution over discrete visual codes at masked positions; transferable ViT backbone
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。

- Teaching tokenizer is fixed patch-intensity quantization, NOT the pretrained dVAE tokenizer. Demonstrates the discrete-target objective only; no claim of BEiT architecture or result equivalence.
