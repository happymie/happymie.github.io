# 026 · MAE

[教学网站](https://happymie.github.io/teaching/#model=26) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_026_mae)

**实现状态：复用上游实现 / Upstream adapter**

高比例随机遮蔽后仅编码可见 patch，再用轻量 decoder 重建 mask patch 的非对称自编码器。

Asymmetric autoencoder that masks 75% of image patches, encodes only the 25% visible tokens with a heavy ViT, and reconstructs pixels via a lightweight decoder.

## 1. 输入、输出与学习目标

- 原模型输入：随机遮蔽大比例 patch 的图像 / Image with a high proportion (e.g., 75%) of randomly masked patches
- 原模型输出：重建的被遮蔽 patch 与预训练视觉 encoder / Reconstructed masked patches during pretraining; high-capacity ViT encoder for downstream fine-tuning
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。
