## 3. 本地实现与 CPU 配置

Two convolutions per scale, contracting path, transposed upsampling and concatenated encoder skips.

```json
{
  "batch_size": 2,
  "width": 8,
  "depth": 3
}
```

配置直接来自实际注册表。宽度、深度、头数或网格尺寸的改变必须满足结构约束；不要把缩小配置的结果写成原模型结果。

**已知差异 / Limitations**

- Random initialization and synthetic data; no original benchmark result or pretrained capability is reproduced.
- Three pooling levels and same-padding instead of the original four-level valid-convolution/crop preset.
