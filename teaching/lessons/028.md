**实现状态：部分机制演示 / Mechanism demo**

EMA teacher 同时充当在线视觉 tokenizer，以图像级 DINO 蒸馏和被遮 patch token 蒸馏联合训练。

Uses the EMA teacher simultaneously as an online visual tokenizer to jointly distill masked patch tokens alongside global [CLS] self-distillation.

## 1. 输入、输出与学习目标

- 原模型输入：同一图像的多裁剪视图与随机遮蔽 patch / Multi-crop augmented views with random block-wise patch masking applied to the student
- 原模型输出：同时具备全局语义和局部 patch 语义的视觉表征 / ViT representations capturing both global image semantics and fine-grained local patch semantics
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。
