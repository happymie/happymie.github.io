# 123 · SiT

[教学网站](https://happymie.github.io/teaching/#model=123) · [返回覆盖表](../docs/COVERAGE.md) · [原图谱结构与数学](https://happymie.github.io/biomed-ai-atlas/#/model/architecture_model_123_sit)

**实现状态：复用上游实现 / Upstream adapter**

SiT 将 DiT 放入 stochastic interpolant 框架，用统一模型显式比较 velocity、score 和 diffusion 参数化。

Places the Diffusion Transformer (DiT) backbone inside a continuous-time Stochastic Interpolant framework to systematically decouple interpolation schedules, model targets, and samplers.

## 1. 输入、输出与学习目标

- 原模型输入：数据样本 x0、噪声 ε、连续时间 t 和可选类别条件 / Data sample x_0 (or latent), Gaussian noise ε, continuous time t ∈ [0,1], and conditioning label c
- 原模型输出：学习到的 velocity/score/noise 场及 ODE/SDE 生成样本 / Samples generated via configurable deterministic ODE or stochastic SDE integrators from the same SiT backbone
- 分辨原模型的必要计算机制、本地缩小配置和没有覆盖的原训练阶段。
- 从数据、损失、梯度到日志完成可检查的学习记录，保留失败与不确定性。
